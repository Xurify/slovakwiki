# Quiz overhaul

## Direction

Use a familiar quiz product rather than an editorial reference layout or a game.

### Quiz home

- Plain heading: “Practice your Slovak.”
- Three topic cards.
- Each card shows level, question count, covered topics, and one Start button.
- No abstract teaching language.
- Use flat, single-color cards with aligned title and description rows.
- Avoid colored top strips, pill chips, soft shadows, and rounded-button stacks.

### Quiz player

- Back link, question count, and progress bar.
- One question card.
- Question first; sentence or dialogue second.
- Three large answer choices.
- One Check answer button.
- After checking, show the correct answer and a short explanation.

### Results

- Score in plain language.
- Missed questions with correct answers.
- Direct links to the relevant Wiki pages.
- Try again and Choose another quiz actions.

## Writing rules

- Use normal English.
- One instruction per question.
- Avoid “evidence,” “cue,” “identify,” “inspect,” and curriculum language.
- Do not reveal an answer in the prompt translation.
- Prefer useful situations and concrete Slovak examples.
- When two questions cover the same rule, the second must add a new use.

## Visual direction

Refined, familiar, and product-like while retaining the existing paper palette and serif voice. Topic cards make the home recognizable as a quiz selection page. The player uses one contained surface with clear hierarchy, large targets, and a single primary action.
