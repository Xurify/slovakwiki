# Wiki utilitarian redesign

## Goal

Turn the Wiki into a fast reference tool for English-speaking Slovak learners. Remove the decorative editorial treatment and make browsing, filtering, and scanning the primary experience.

## Direction

- Neutral white and charcoal palette.
- System sans-serif typography throughout the Wiki.
- Slovak blue reserved for links, focus, and selected controls.
- Compact application header and two-column reference layout.
- Persistent left navigation for content type and topic.
- Main content contains search, alphabetical navigation, and dense result rows.
- No hero, slogans, cards, oversized typography, cream background, plum, or coral.

## Responsive behavior

Desktop uses a sticky left navigation and wide results table. Mobile collapses navigation into horizontal controls and reduces each result to Slovak term, English meaning, and metadata.

## Interaction

Search filters immediately. Type and topic filters can be combined. Alphabet links narrow results to a letter. Clear restores the full index. All entry rows remain direct links.

## Verification

Check search and filter behavior, every entry link, 1440px and 390px layouts, horizontal overflow, console errors, Svelte diagnostics, tests, and production build.
