# Orthography, Punctuation, and Typography

Use this when writing or correcting any Slovak that will be published: site copy, examples, lesson text, emails. Sounds and stress live in [phonology-and-orthography.md](phonology-and-orthography.md). The authority is _Pravidlá slovenského pravopisu_ (PSP, JÚĽŠ); verify unusual cases there.

## 1. Characters

- Slovak letters with diacritics: `á ä č ď é í ĺ ľ ň ó ô ŕ š ť ú ý ž` (and capitals `Á Ä Č Ď É Í Ĺ Ľ Ň Ó Ô Ŕ Š Ť Ú Ý Ž`).
- `ď ť ľ` carry a caron that looks like an apostrophe in many fonts. Never type `d'`, `t'`, `l'` with a real apostrophe: `ďakujem`, not `d'akujem`.
- Store text in Unicode NFC (precomposed characters). The site normalizes to NFC when grading answers.
- `ä` occurs only after labials: `mäso, päť, deväť, pamäť, väčší, mäkký`.
- `ô` never starts a word except `ôsmy` and related forms; it is common inside words: `kôň, stôl, môj, pôjdem, dôležitý, vôňa`.
- Czech letters `ř, ě, ů` do not exist in Slovak. Their presence means Czech leaked in.

## 2. `i/í` or `y/ý`

| After                                                       | Write                                     | Examples                                      |
| ----------------------------------------------------------- | ----------------------------------------- | --------------------------------------------- |
| hard consonants `h, ch, k, g`; hard-pronounced `d, t, n, l` | `y/ý` (native words)                      | `chyba, kytica, dym, ty, ryby, noviny, hýbať` |
| soft consonants `ž, š, č, c, j, dz, dž, ď, ť, ň, ľ`         | `i/í`                                     | `žiak, šiška, čistý, cibuľa, cítiť`           |
| neutral consonants `b, m, p, r, s, v, z, f, l`              | `i/í`, except in the selected words below | `biť, mi, pivo, riadok, sila, víno, zima`     |

`d, t, n, l` + `i/í/e/ie` are pronounced soft in native words (`deti` = [ďeťi], `ticho` = [ťicho], `nikdy` = [ňigdy]); before `y` they stay hard. The spelling is the only signal: `ty` (you) vs. `ti` (to you), `dym` vs. `dieťa`. Loanwords keep hard pronunciation before `i`: `kino`, `gitara`, `diktát`, `politika`, `technika`.

### Selected words (vybrané slová)

After `b, m, p, r, s, v, z, l`, write `y/ý` in these roots and every word derived from them (`byt → bytový, obyvateľ`; `ryba → rybár, rybací`). Core list (abbreviated; the school list has more rare items):

| After | Roots                                                                                                                                  |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `b`   | `by, aby, byť (exist), bydlo, bydlisko, bývať, byt, nábytok, obyvateľ, bytosť, bylina, býk, bystrý, Bystrica, kobyla, dobytok, obyčaj` |
| `m`   | `my, mykať, myslieť, myseľ, priemysel, mýliť sa, hmyz, myš, myť, mydlo, mýto, šmýkať sa, žmýkať, hmýriť sa, Myjava`                    |
| `p`   | `pýcha, pyšný, pýtať (sa), pykať, kopyto, klopýtať, pysk, prepych, pýr`                                                                |
| `r`   | `ryba, rybník, rys, rýchly, rýchlik, ryť, rýpať, rýľ, rytier, ryža, hrýzť, kryť, strýko, trýzniť, koryto, rýdzi, ryčať`                |
| `s`   | `syn, sýty, sypať, syr, sýkorka, sychravý, sykať, sýpka, syseľ`                                                                        |
| `v`   | `vy, vysoký, výskať, vyť, vydra, vyžla, výr, vyhňa, zvyk, zvyčajne`; and the prefixes `vy-`/`vý-` (`vyjsť, výlet, výborný`)            |
| `z`   | `jazyk, nazývať (sa), pozývať, vyzývať, ozývať sa`                                                                                     |
| `l`   | `lyže, lyžica, lysý, lyko, lýtko, plyn, plynúť, plytký, slýchať, mlyn, blyšťať sa, pomaly`                                             |

Meaning contrasts that hinge on this: `byť` (be) / `biť` (beat), `my` (we) / `mi` (to me), `výr` (eagle owl) / `vír` (whirlpool).

### `i/y` in endings

- Masculine animate nominative plural: `-i/-í` (`chlapi`, `pekní chlapi`); other plurals of hard and neutral stems: `-y/-é` (`stromy`, `ženy`, `pekné ženy`); soft stems keep `-i/-e` (`veci`, `kosti`, `ulice`).
- The past tense plural is always `-li`: `ženy boli`, `stromy rástli`, `deti prišli`. Slovak has no `-ly` past (that is Czech: `*ženy byly`).
- Instrumental singular masculine/neuter adjectives `-ým`, plural dative `-ým`, plural instrumental `-ými`: `s pekným domom`, `peknými domami`.

## 3. Prepositions that change shape

| Base | Long form | When                                            | Examples                                                     |
| ---- | --------- | ----------------------------------------------- | ------------------------------------------------------------ |
| `v`  | `vo`      | before `v`, `f`, and some clusters/pronouns     | `vo vode`, `vo februári`, `vo štvrtok`, `vo dvore`, `vo mne` |
| `s`  | `so`      | before `s, z, š, ž`, and some clusters/pronouns | `so sestrou`, `so Zuzanou`, `so ženou`, `so psom`, `so mnou` |
| `z`  | `zo`      | before `s, z, š, ž`, and some clusters/pronouns | `zo školy`, `zo Žiliny`, `zo stola`, `zo mňa`                |
| `k`  | `ku`      | before `k`, `g`, and some pronouns              | `ku koncu`, `ku Katke`, `ku mne`                             |

`s` (with) + instrumental and `z` (from, out of) + genitive are different prepositions. Write `s bratom` even though it sounds like [zbratom]; never `*z bratom` for "with my brother". `Prišiel so sestrou zo školy.`

## 4. Capitalization

| Category                                 | Rule                                          | Examples                                                                              |
| ---------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------- |
| nationality / inhabitant nouns           | capital                                       | `Slovák, Slovenka, Angličan, Bratislavčan, Európan`                                   |
| adjectives, languages, adverbs           | lowercase                                     | `slovenský, slovenčina, po slovensky, anglický`                                       |
| days, months                             | lowercase                                     | `v pondelok, v máji`                                                                  |
| towns and villages                       | every word except prepositions                | `Banská Bystrica, Nové Zámky, Nové Mesto nad Váhom`                                   |
| mountains, lakes, seas, regions          | first word + proper names                     | `Vysoké Tatry, Malé Karpaty, Štrbské pleso, Čierne more`                              |
| streets, squares                         | first word + proper names                     | `Obchodná ulica, Hviezdoslavovo námestie, Námestie SNP, Ulica 29. augusta`            |
| institutions                             | first word + proper names                     | `Národná rada Slovenskej republiky, Slovenská národná galéria, Univerzita Komenského` |
| holidays                                 | first word                                    | `Vianoce, Veľká noc, Štedrý deň, Nový rok, Deň matiek`                                |
| titles, offices, professions             | lowercase                                     | `pán Novák, pani doktorka, prezident Slovenskej republiky`                            |
| formal address to one person in a letter | capital                                       | `Vy, Vás, Vám, Váš, Vaša`                                                             |
| headings and titles of works             | sentence case: first word + proper names only | `Slovesá pohybu v praxi`, not `*Slovesá Pohybu V Praxi`                               |

## 5. Commas

### Always

- **Before a subordinate clause**, and on both sides when it is embedded: `Viem, že prídeš.` `Neviem, kde býva.` `Kniha, ktorú čítam, je dobrá.` This covers `že, aby, keď, ak, lebo, pretože, keďže, hoci, kým, či, ktorý, čo, kde, kam, kedy, ako`.
- **Before contrastive conjunctions**: `ale, no, lenže, avšak, ba, ibaže`: `Chcel prísť, ale nemohol.`
- **With paired conjunctions**: `Buď zavoláš, alebo napíšeš.` `Neprišiel ani Peter, ani Jana.` `Nielen pracuje, ale aj študuje.` `Neviem, či zostane, alebo odíde.`
- **Around direct address**: `Peter, poď sem.` `Ďakujem, Jana.` `Dobrý deň, pán Novák.`
- **After a sentence-initial interjection or answer word**: `Áno, rozumiem.` `Nie, ďakujem.` `Ach, to je škoda.`
- **Around inserted `prosím`** and other parentheticals: `Môžete mi, prosím, pomôcť?`
- **Around appositions**: `Bratislava, hlavné mesto Slovenska, leží na Dunaji.`

### Never

- Before `a, aj, i, alebo, ani` joining equal items or clauses: `Peter spí a Jana číta.` `Kúpim chlieb alebo rožky.` (Exception: `a` with an added meaning takes a comma: `, a to`, `, a preto`, `, a tak`, `, a teda`. PSP also allows an optional comma when the clauses clearly contrast.)
- Before `ako`/`než` comparing words, not clauses: `Je vyšší ako ja.` But: `Je vyšší, ako som si myslel.`
- Before `ako` meaning "as, in the role of": `Pracujem ako učiteľ.`
- Before the last item of a list (no serial comma) or before `atď.`: `jablká, hrušky a slivky`; `jablká, hrušky, slivky atď.`

### Compound conjunctions

| Comma inside                                                                                                            | No comma inside                                                                                                |
| ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `preto, lebo` · `preto, aby` · `tak, že` · `napriek tomu, že` · `vďaka tomu, že` · `namiesto toho, aby` · `odvtedy, čo` | `aj keď` · `ako keby` · `hneď ako` · `len čo` · `až keď` (comma goes before the whole: `Pochopil to, až keď…`) |

`skôr ako`, `predtým ako`, `potom ako`, `hneď ako` are single conjunctions: no inner comma at the start of a sentence (`Skôr ako pôjdeme domov, dohodneme sa.`). Mid-sentence, the comma moves inside only when the adverb is stressed and belongs to the main clause: `Umrela skôr, ako ju dopravili do nemocnice.`

`Čím skôr, tým lepšie.`

## 6. Letters and emails

```text
Dobrý deň,                        comma → next line starts lowercase
ďakujem za Vašu správu. ...

Vážená pani Nováková!             exclamation mark → next line starts with a capital
Ďakujem Vám za ...

S pozdravom                       no comma after the closing
Ján Novák
```

Place and date line: `V Bratislave 10. apríla 2026` or `Bratislava 10. 4. 2026` (no comma).

## 7. Numbers, dates, units

| Item              | Slovak convention                          | Example                                                   |
| ----------------- | ------------------------------------------ | --------------------------------------------------------- |
| decimal separator | comma                                      | `3,5`; `2,50 €`                                           |
| thousands         | space (optional for four digits)           | `10 000`, `1 250 000`, `2026` (years: none)               |
| ordinal number    | period after the digit                     | `1. mája`, `21. storočie`, `3. ročník`                    |
| date              | day. month. year, spaces after the periods | `10. 4. 2026`, `10. apríla 2026`                          |
| time              | period or colon, consistent within a text  | `o 14.30 h`, `14:30`                                      |
| percent           | space in both uses                         | `5 %` (päť percent); `5 % roztok` or `5-percentný roztok` |
| currency          | after the number, with a space             | `5 €`, `5 eur`                                            |
| temperature       | space before `°C`                          | `20 °C`                                                   |
| ranges            | en dash `–` with spaces on both sides      | `1939 – 1945`, `5 – 10 kg`, `1. mája – 15. júna`          |

## 8. Quotation marks, dashes, hyphens

- Quotation marks: `„takto“` (opening low `„` U+201E, closing high `“` U+201C). Nested: `‚takto‘`. Not English `"…"` in published Slovak.
- En dash `–` with spaces for a break in a sentence: `Prišiel – a hneď odišiel.` Also for ranges and routes.
- Hyphen `-` (spojovník) joins two equal parts or marks a prefix/abbreviation: `slovensko-anglický slovník`, `Rakúsko-Uhorsko`, `e-mail`, `5-ročný` (with digits).

## 9. Abbreviations and titles

`napr.` (for example), `atď.` (etc.), `tzv.` (so-called), `t. j.` (i.e.), `resp.` (or rather), `č.` (number), `s. r. o.` (Ltd.), `a. s.` (plc). Multi-word abbreviations have a space after each period: `t. j.`, `s. r. o.`

Academic titles come before the name, with `PhD.` and `CSc.` after a comma: `Ing. Ján Novák`, `Mgr. Eva Kováčová, PhD.`, `MUDr.` (physician), `JUDr.` (law), `doc.`, `prof.`

## 10. One word or two

| Together                                                                                                                           | Apart                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dovidenia`, `naozaj`, `napríklad`, `nakoniec`, `zatiaľ`, `doteraz`, `nahlas`, `potichu`, `zadarmo`, `naspäť`, `znova`, `medzitým` | `po slovensky`, `na zdravie`, `dobrú chuť`, `všetko najlepšie`                                                                                    |
| `ne-` with verbs: `nemám`, `nebol`, `nechcem`                                                                                      | `nie som`, `nie je`, `nie sú` (present of `byť`)                                                                                                  |
| `ne-` with adjectives/adverbs: `nepekný`, `nedobre`                                                                                | contrast or degree: `nie pekný, ale krásny`; `nie veľmi`                                                                                          |
| `preto` (therefore), `potom` (then), `zato` (but on the other hand), `nato` (thereupon), `dokonca` (even), `akoby` (as if)         | `pre to` (for that thing), `po tom` (after that thing), `za to` (for it), `na to` (onto/for it), `do konca` (until the end), `ako by` (how would) |
