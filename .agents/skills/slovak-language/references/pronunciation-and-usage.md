# Pronunciation, Usage, and Production Patterns

## Pronunciation

Spelling is comparatively regular. Stress normally falls on the first syllable; prepositions can form a stress unit with the following word. Vowels `a e i/y o u` contrast with long `á é í/ý ó ú`; `ä` is usually pronounced like `e` in standard speech. Diphthongs `ia, ie, iu, ô` count as long. `r` and `l` can be syllabic: `krk`, `vlk`, `štvrť`.

Key consonants: `c` = ts, `č` = ch, `dz` = voiced _dz_ as in _adze_, `dž` = j in _jam_, `š` = sh, `ž` = s in _measure_, `j` = y, `ch` = German _Bach_, `ľ` is soft l, and `ť/ď/ň` are soft t/d/n. Final voiced obstruents are devoiced (`dub` ends [p]); voicing assimilates in clusters. `v` may sound close to [u̯]/[w] at word end or before many consonants.

## Address and politeness

Use `Dobrý deň` with strangers, older people, and professional contexts; `Ahoj/Čau` only when informal. `Dovidenia` is the safe neutral/formal goodbye. `Prosím` can mean please, here you are, or you're welcome; `Ďakujem` takes thanks. Use `Prepáč` with `ty`, `Prepáčte` with `vy`.

Do not shift to `ty` without an invitation. Common offer: `Môžeme si tykať?` When writing an email, use `Vážený pán / Vážená pani` for formal correspondence, `Dobrý deň` for neutral professional mail, and capitalize forms of formal address for one person (`Vám`, `Váš`).

## High-yield chunks

| Need                  | Slovak                                               |
| --------------------- | ---------------------------------------------------- |
| introduce self        | `Volám sa ...` / `Som ...`                           |
| origin/residence      | `Som z ...` / `Bývam v ...`                          |
| ask identity          | `Ako sa voláš/voláte?`                               |
| understand            | `Rozumiem.` / `Nerozumiem.`                          |
| ask repetition        | `Môžete to, prosím, zopakovať?`                      |
| request               | `Prosím si ...` / `Chcel by som / Chcela by som ...` |
| ability vs. knowledge | `Môžem ...` / `Viem ...`                             |
| like                  | `Mám rád ...` / `Mám rada ...`                       |
| need                  | `Potrebujem ...` / `Musím ...`                       |
| time                  | `Koľko je hodín?` / `Je ... hodín.`                  |
| directions            | `Kde je ...?` / `Ako sa dostanem do ...?`            |

For a male speaker use `rád, chcel by som, bol som`; for a female speaker use `rada, chcela by som, bola som`. For mixed/plural groups, masculine animate governs agreement.

## Common English-speaker interference

- Do not add articles: `Mám auto`, not *`mám jedno auto` unless _one_ is intended.
- Do not use nominative after every preposition: `do práce`, `v práci`, `s prácou`.
- Do not translate English progressive with a special tense: `Teraz pracujem.`
- Do not use `byť` where Slovak uses a case/verb: `Mám 25 rokov`, not *`som 25 rokov`.
- Use `mať rád` for liking people/things, not a literal `páčiť sa` copy. `Páči sa mi tá kniha` means the book pleases me.
- Distinguish `poznať` (know/be familiar with a person/place) from `vedieť` (know a fact/know how). `Viem po slovensky` means I know Slovak/can speak it.
- Distinguish `domov` (homeward), `doma` (at home), `dom` (house/home noun).
- Do not overuse explicit `ja, ty, on`; verb endings usually suffice.

## Correction protocol

For learner text, present:

1. `Opravená verzia` — a natural corrected text.
2. `Kľúčové opravy` — at most five high-value items in `original → correction — reason` form.
3. `Skús teraz` — 1-3 minimal personalized prompts targeting the same pattern.

For an advanced learner, distinguish grammar error from stylistic improvement. Do not label a valid colloquial form as wrong merely because a formal alternative exists.

## Translation protocol

Ask only if the missing choice changes the result materially: speaker gender, `ty` vs. `vy`, country-specific legal/technical terminology, or intended tone. Otherwise provide the most neutral natural version and briefly flag optional alternatives. Preserve proper names, numbers, and formatting. Translate idioms by effect; do not calque English phrasal verbs or article logic.
