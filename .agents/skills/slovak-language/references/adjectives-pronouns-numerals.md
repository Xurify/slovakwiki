# Adjectives, Pronouns, and Numerals

Use this for agreement tables, comparison, pronoun choice (short vs. long forms), and every number-related form: cardinals, ordinals, clock time, money, age, fractions, and decimals.

## 1. Adjectives

### Hard type: `pekný`

| Case | m. sg.                  | f. sg. | n. sg.  | pl.                                 |
| ---- | ----------------------- | ------ | ------- | ----------------------------------- |
| N    | pekný                   | pekná  | pekné   | pekní (m. anim.) / pekné (others)   |
| G    | pekného                 | peknej | pekného | pekných                             |
| D    | peknému                 | peknej | peknému | pekným                              |
| A    | pekného (anim.) / pekný | peknú  | pekné   | pekných (m. anim.) / pekné (others) |
| L    | peknom                  | peknej | peknom  | pekných                             |
| I    | pekným                  | peknou | pekným  | peknými                             |

Rhythmic law: after a long syllable the ending shortens. `krásny, krásna, krásne; krásneho, krásnemu, krásnom, krásnym`; pl. `krásni/krásne, krásnych, krásnym, krásnymi`. The instrumental `krásnou` keeps `ou`. Never `*krásný`, `*krásného`.

### Soft type: `cudzí`

| Case | m. sg.                   | f. sg. | n. sg.   | pl.                                  |
| ---- | ------------------------ | ------ | -------- | ------------------------------------ |
| N    | cudzí                    | cudzia | cudzie   | cudzí (m. anim.) / cudzie (others)   |
| G    | cudzieho                 | cudzej | cudzieho | cudzích                              |
| D    | cudziemu                 | cudzej | cudziemu | cudzím                               |
| A    | cudzieho (anim.) / cudzí | cudziu | cudzie   | cudzích (m. anim.) / cudzie (others) |
| L    | cudzom                   | cudzej | cudzom   | cudzích                              |
| I    | cudzím                   | cudzou | cudzím   | cudzími                              |

Decide by the nominative ending: `-ý/-y` follows `pekný` (`posledný`, `ranný`); `-í/-i` follows `cudzí` (`tretí → tretieho`, `domáci → domáceho`, `včerajší → včerajšieho`). All comparatives (`lepší`, `väčší`, `krajší`) are soft.

### Possessive adjectives: `otcov`, `matkin`

Formed from one animate owner: masculine `-ov` (`Peter → Petrov`, `brat → bratov`), feminine `-in` (`mama → mamin`, `Jana → Janin`, `sestra → sestrin`).

| Case | m. sg.                  | f. sg.  | n. sg.  | pl.                                   |
| ---- | ----------------------- | ------- | ------- | ------------------------------------- |
| N    | otcov                   | otcova  | otcovo  | otcovi (m. anim.) / otcove (others)   |
| G    | otcovho                 | otcovej | otcovho | otcových                              |
| D    | otcovmu                 | otcovej | otcovmu | otcovým                               |
| A    | otcovho (anim.) / otcov | otcovu  | otcovo  | otcových (m. anim.) / otcove (others) |
| L    | otcovom                 | otcovej | otcovom | otcových                              |
| I    | otcovým                 | otcovou | otcovým | otcovými                              |

`matkin` takes the same endings: `matkina kniha`, `s matkiným autom`, `v Janinom byte`. When to use a possessive adjective instead of a genitive: see [discourse-and-verb-precision.md](discourse-and-verb-precision.md) §5.

### Comparison

| Formation      | Examples                                                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `-ší`          | `nový → novší`, `starý → starší`, `mladý → mladší`, `dlhý → dlhší`, `krátky → kratší`, `drahý → drahší`, `slabý → slabší`, `tichý → tichší`                                    |
| `-ší` + change | `vysoký → vyšší`, `nízky → nižší`, `úzky → užší`, `široký → širší`, `blízky → bližší`, `hlboký → hlbší`, `ťažký → ťažší`, `ľahký → ľahší`, `sladký → sladší`                   |
| `-ejší`        | `rýchly → rýchlejší`, `lacný → lacnejší`, `silný → silnejší`, `čistý → čistejší`, `múdry → múdrejší`, `teplý → teplejší`, `zaujímavý → zaujímavejší`, `dôležitý → dôležitejší` |
| suppletive     | `dobrý → lepší`, `zlý → horší`, `veľký → väčší`, `malý → menší`, `pekný → krajší`                                                                                              |

Superlative: `naj-` + comparative (`najlepší`, `najväčší`, `najkrajší`). Comparatives and superlatives decline like `cudzí`.

```text
Je starší ako ja. / Je starší než ja.        than: ako (neutral), než (slightly bookish)
Je o dva roky starší.                         by how much: o + accusative
Je taký vysoký ako brat. Je rovnako vysoký.   equality
Je to dvakrát väčšie.                         multiples
čo najrýchlejšie                              as fast as possible
Čím skôr, tým lepšie.                         the sooner, the better
```

### Adverbs

| From               | Ending | Examples                                                   |
| ------------------ | ------ | ---------------------------------------------------------- |
| most adjectives    | `-o`   | `rýchlo`, `ticho`, `vysoko`, `ďaleko`, `blízko`, `neskoro` |
| many `-ný`, others | `-e`   | `dobre`, `zle`, `pekne`, `krásne`, `presne`, `správne`     |
| `-ský`, `-cký`     | `-y`   | `(po) slovensky`, `anglicky`, `prakticky`, `logicky`       |
| irregular          | —      | `pomalý → pomaly`                                          |

The `-o`/`-e` choice is lexical; some adjectives allow both. Verify uncommon ones.

Comparative adverbs end in `-šie`/`-ejšie`: `rýchlejšie`, `pomalšie`, `krajšie`. Irregular: `dobre → lepšie`, `zle → horšie`, `veľa → viac`, `málo → menej`, `skoro → skôr`, `neskoro → neskôr`, `ďaleko → ďalej`, `blízko → bližšie`, `vysoko → vyššie`. Superlative: `najlepšie`, `najviac`, `najskôr`.

## 2. Personal and reflexive pronouns

| Case | ja      | ty       | on / ono             | ona      | my   | vy   | oni / ony                  | reflexive |
| ---- | ------- | -------- | -------------------- | -------- | ---- | ---- | -------------------------- | --------- |
| N    | ja      | ty       | on / ono             | ona      | my   | vy   | oni / ony                  | —         |
| G    | mňa, ma | teba, ťa | jeho, ho, neho       | jej, nej | nás  | vás  | ich, nich                  | seba, sa  |
| D    | mne, mi | tebe, ti | jemu, mu, nemu       | jej, nej | nám  | vám  | im, nim                    | sebe, si  |
| A    | mňa, ma | teba, ťa | jeho, ho, neho, -ňho | ju, ňu   | nás  | vás  | ich; after prep. nich / ne | seba, sa  |
| L    | mne     | tebe     | ňom                  | nej      | nás  | vás  | nich                       | sebe      |
| I    | mnou    | tebou    | ním                  | ňou      | nami | vami | nimi                       | sebou     |

How to choose the form:

- **Short forms** (`ma, ťa, mi, ti, ho, mu, sa, si`) are unstressed clitics in second position: `Páči sa mi to.` `Včera som ho videl.`
- **Long forms** (`mňa, teba, mne, tebe, jeho, jemu, seba, sebe`) carry stress or contrast and can start a sentence: `Mne sa to páči, jemu nie.` `Teba hľadám, nie jeho.`
- **After a preposition**, use the long form; third person takes `n-`: `pre mňa`, `ku mne`, `so mnou`, `o tebe`, `k nemu`, `s ním`, `o ňom`, `bez nej`, `na ňu`, `s ňou`, `pre nich`, `s nimi`.
- **Third-person plural accusative after a preposition** splits by gender: `Čakám na nich.` (men or mixed group) vs. `Čakám na ne.` (women, children, things).
- **Contracted forms** `preňho, naňho, doňho, oňho, zaňho` are standard alternatives to `pre neho`, `na neho`…

`seba/sa`, `sebe/si`, `sebou` refer back to the subject in any person: `Vezmi si to so sebou.` `Myslí len na seba.`

## 3. Possessive pronouns

| Case | m. sg.              | f. sg. | n. sg. | pl.                               |
| ---- | ------------------- | ------ | ------ | --------------------------------- |
| N    | môj                 | moja   | moje   | moji (m. anim.) / moje (others)   |
| G    | môjho               | mojej  | môjho  | mojich                            |
| D    | môjmu               | mojej  | môjmu  | mojim                             |
| A    | môjho (anim.) / môj | moju   | moje   | mojich (m. anim.) / moje (others) |
| L    | mojom               | mojej  | mojom  | mojich                            |
| I    | mojím               | mojou  | mojím  | mojimi                            |

`tvoj` and `svoj` follow `môj` (`tvojho`, `svojím`). `náš`/`váš`: `náš, nášho, nášmu, nášho/náš, našom, naším`; f. `naša, našej, našej, našu, našej, našou`; n. `naše`; pl. `naši/naše, našich, našim, našich/naše, našich, našimi`. Mind the length contrast: instrumental singular `mojím`, `naším` vs. dative plural `mojim`, `našim`.

`jeho`, `jej`, `ich` never change: `s jeho bratom`, `o jej práci`.

`svoj` points to the subject of its clause: `Peter predal svoj dom.` (his own) vs. `Peter predal jeho dom.` (someone else's). With `ja/ty/my/vy` subjects use `svoj` too; `môj/tvoj/náš/váš` only for emphasis or contrast (`Nechajte si tie vaše peniaze.`).

Drop possessives where Slovak finds them obvious: `Umyl som si ruky.` (not `*moje ruky`), `Zavolám mame.`

## 4. Demonstratives, interrogatives, relatives

`ten`:

| Case | m. sg.             | f. sg. | n. sg. | pl.                          |
| ---- | ------------------ | ------ | ------ | ---------------------------- |
| N    | ten                | tá     | to     | tí (m. anim.) / tie (others) |
| G    | toho               | tej    | toho   | tých                         |
| D    | tomu               | tej    | tomu   | tým                          |
| A    | toho (anim.) / ten | tú     | to     | tých (m. anim.) / tie        |
| L    | tom                | tej    | tom    | tých                         |
| I    | tým                | tou    | tým    | tými                         |

`tento` adds `-to` to every form (`tohto`, `tomuto`, `túto`, `týmto`, pl. `títo/tieto`); `tamten` adds `tam-`. Presentational `to` does not agree: `To je môj brat.` `To sú moji rodičia.`

`kto`: `koho, komu, koho, o kom, s kým`; it takes masculine singular agreement: `Kto prišiel?` `čo`: `čoho, čomu, čo, o čom, s čím`; neuter: `Čo sa stalo?` `nikto/niekto` and `nič/niečo` decline the same way (`nikoho, nikomu, s nikým`; `ničoho, ničomu, s ničím`).

`ktorý` (which; who/that in relative clauses) declines like `pekný` and agrees with its antecedent in gender and number, while taking its case from its own clause:

```text
To je muž, ktorý tu býva.          ktorého poznám.     ktorému som písal.
            o ktorom hovoríme.      s ktorým pracujem.
To je žena, ktorá tu býva / ktorú poznám / ktorej som písal / s ktorou pracujem.
To je muž, ktorého auto stojí vonku.     (whose = genitive of ktorý)
```

`čí, čia, čie` (whose?, interrogative) follow `cudzí`: `Čí je to kľúč?` `aký` (what kind) and `ktorý` follow `pekný`.

### Indefinite and negative series

| Base    | some-      | no-                | any-at-all                 |
| ------- | ---------- | ------------------ | -------------------------- |
| `kto`   | `niekto`   | `nikto`            | `hocikto`, `ktokoľvek`     |
| `čo`    | `niečo`    | `nič`              | `hocičo`, `čokoľvek`       |
| `kde`   | `niekde`   | `nikde`            | `hocikde`, `kdekoľvek`     |
| `kam`   | `niekam`   | `nikam`            | `hocikam`, `kamkoľvek`     |
| `kedy`  | `niekedy`  | `nikdy`            | `hocikedy`, `kedykoľvek`   |
| `ako`   | `nejako`   | `nijako`           | `hocijako`, `akokoľvek`    |
| `aký`   | `nejaký`   | `nijaký`, `žiadny` | `hocijaký`, `akýkoľvek`    |
| `ktorý` | `niektorý` | `žiadny`           | `hociktorý`, `ktorýkoľvek` |

Negative words require a negated verb, and several can stack: `Nikto nič nevedel.` `Nikdy nikam nechodím.` Colloquial central and eastern speech uses `da-` (`dakto`, `dačo`, `dakde`) for `nie-`; keep it out of standard text.

### `všetok`, `sám`, `každý`

`všetok`: m. `všetok, všetkého, všetkému, všetok, všetkom, všetkým`; f. `všetka, všetkej, všetkej, všetku, všetkej, všetkou`; n. `všetko`; pl. `všetci/všetky, všetkých, všetkým, všetkých/všetky, všetkých, všetkými`. Usage: [advanced-forms-and-usage.md](advanced-forms-and-usage.md) §1.

`sám, sama, samo`; pl. `sami` (m. anim.) / `samy`: alone, by oneself. `Som tu sám/sama.` `Urobili to sami.`

`každý`, `iný`, `celý`, `istý` decline like `pekný`.

## 5. Numerals

### Cardinals

```text
0 nula       10 desať        20 dvadsať        100 sto          1 000 tisíc
1 jeden      11 jedenásť     21 dvadsaťjeden   200 dvesto       2 000 dvetisíc
2 dva        12 dvanásť      30 tridsať        300 tristo       5 000 päťtisíc
3 tri        13 trinásť      40 štyridsať      400 štyristo     1 000 000 milión
4 štyri      14 štrnásť      50 päťdesiat      500 päťsto       2 000 000 dva milióny
5 päť        15 pätnásť      60 šesťdesiat     600 šesťsto      5 000 000 päť miliónov
6 šesť       16 šestnásť     70 sedemdesiat    700 sedemsto     10⁹ miliarda
7 sedem      17 sedemnásť    80 osemdesiat     800 osemsto
8 osem       18 osemnásť     90 deväťdesiat    900 deväťsto
9 deväť      19 devätnásť
```

In the basic form, compound cardinals are written as one word: `dvadsaťjeden`, `stodvadsaťpäť`, `dvetisícdvadsaťšesť`. When declined or in the masculine-personal form, the units are written separately: `dvadsiatich dvoch`, `dvadsiati dvaja muži`. An older order also exists for 21–99 (`jedenadvadsať`, `dvaadvadsať`). Long numbers are normally written in digits.

### Gender and case of 1–4

| Case | 1 (m. / f. / n.)               | 2                                              | 3                     | 4                         |
| ---- | ------------------------------ | ---------------------------------------------- | --------------------- | ------------------------- |
| N    | jeden / jedna / jedno          | dva (m. inan.), dve (f., n.), dvaja (m. anim.) | tri, traja (m. anim.) | štyri, štyria (m. anim.)  |
| G    | jedného / jednej / jedného     | dvoch                                          | troch                 | štyroch                   |
| D    | jednému / jednej / jednému     | dvom                                           | trom                  | štyrom                    |
| A    | jedného, jeden / jednu / jedno | dva, dve; dvoch (m. anim.)                     | tri; troch (m. anim.) | štyri; štyroch (m. anim.) |
| L    | jednom / jednej / jednom       | dvoch                                          | troch                 | štyroch                   |
| I    | jedným / jednou / jedným       | dvoma                                          | troma, tromi          | štyrmi                    |

`päť` and up: `päť, piatich, piatim, päť (m. anim. piatich), piatich, piatimi`; likewise `šiestich`, `siedmich`, `ôsmich`, `deviatich`, `desiatich`. `sto` and `tisíc` usually stay unchanged: `pred sto rokmi`.

`jedny` counts plural-only nouns (`jedny dvere`); `jedni` means "some (people)": `Jedni súhlasia, iní nie.`

### Which noun form follows

| Number                         | Noun                | Verb in the past     | Example                                       |
| ------------------------------ | ------------------- | -------------------- | --------------------------------------------- |
| 1                              | nominative singular | agrees with the noun | `Prišiel jeden študent.`                      |
| 2–4                            | nominative plural   | plural               | `Prišli dve študentky.` `Stoja tam tri autá.` |
| `dvaja, traja, štyria` (men)   | nominative plural   | plural               | `Prišli dvaja bratia.`                        |
| 5+, `veľa`, `niekoľko`, `pár`  | genitive plural     | neuter singular      | `Prišlo päť študentov.` `Bolo tam veľa ľudí.` |
| `piati, šiesti…` (men, marked) | nominative plural   | plural               | `Prišli piati študenti.`                      |
| compounds ending 1–4 (21, 32…) | genitive plural     | neuter singular      | `dvadsaťjeden rokov`, `tridsaťdva eur`        |

The last row is a common error: `Mám dvadsaťdva rokov.`, not `*dvadsaťdva roky`.

### Ordinals

`prvý, druhý, tretí, štvrtý, piaty, šiesty, siedmy, ôsmy, deviaty, desiaty, jedenásty, dvanásty, …, dvadsiaty, tridsiaty, štyridsiaty, päťdesiaty, …, stý, dvojstý, tisíci`. Compound ordinals are separate words, with tens and units both ordinal: `dvadsiaty prvý`, `tridsiaty druhý`. In long ordinals such as years, thousands and hundreds stay cardinal and are written together with the tens, the units separately: `tisícdeväťstoosemdesiaty deviaty`, `stodvadsiaty štvrtý`. In practice say `v roku 1989`. In digits, an ordinal takes a period: `1. mája`, `21. storočie`, `3. trieda`.

`tretí` and `tisíci` decline like `cudzí` (`tretieho`, `tisíceho`); the rest like `pekný`.

### Numbers as nouns

`jednotka, dvojka, trojka, štvorka, päťka, šestka, sedmička, osmička, deviatka, desiatka, stovka, tisícka` name school grades (1 = best, 5 = fail), tram and bus lines (`Idem deviatkou.`), rooms, and banknotes (`stovka` = 100-euro note).

### Clock time

```text
Koľko je hodín?        Je jedna hodina. Sú dve / tri / štyri hodiny. Je päť hodín.
At what time?          o jednej, o druhej, o tretej … o dvanástej     (o + feminine locative: cardinal `jednej` for 1, ordinals for 2–12)
24-hour (official)     o štrnástej tridsať (14:30); written o 14.30 h or 14:30
half past              Je pol tretej. (2:30, "half of the third")    o pol ôsmej (7:30)
quarter past / to      Je štvrť na päť. (4:15)    Je trištvrte na osem. (7:45)
minutes                Je päť minút po ôsmej. (8:05)
ranges                 od piatej do šiestej; medzi treťou a štvrtou; okolo piatej
```

### Money, age, percentages

```text
jedno euro, dve eurá, päť eur            jeden cent, dva centy, päť centov
Stojí to dve eurá päťdesiat (centov).    written 2,50 €
Mám dvadsať rokov. Má jeden rok. Má dva roky. Koľko máš rokov?
jedno percento, dve percentá, päť percent        written 5 %
```

### Multiples, fractions, decimals

```text
raz, dvakrát, trikrát, štyrikrát, päťkrát, niekoľkokrát, veľakrát
prvýkrát / prvý raz; dvojnásobný (double), dvojnásobok (twice the amount)
pol, polovica; tretina; štvrť, štvrtina; pätina; desatina; stotina
pol hodiny, štvrť hodiny, trištvrte hodiny; jeden a pol, dva a pol
dve tretiny, päť tretín
0,5 nula celá päť     1,2 jedna celá dva     2,5 dve celé päť     5,2 päť celých dva
```

The decimal comma is read `celá/celé/celých`, agreeing with the whole number like a feminine noun counted after 1, 2–4, 5+.

### Decades, centuries, dates

`v osemdesiatych rokoch` (in the eighties), written `v 80. rokoch`; `v 20. storočí` (`v dvadsiatom storočí`); dates use the genitive ordinal: `Narodil sa dvadsiateho štvrtého decembra.` See [advanced-forms-and-usage.md](advanced-forms-and-usage.md) §10 for numeral cases in prepositional phrases.
