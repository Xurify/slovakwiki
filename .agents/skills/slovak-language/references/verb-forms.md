# Verb Forms: Conjugation, Past, Future, Imperative, Participles

Use this to produce any finite or non-finite verb form. For which aspect to choose, see [aspect-and-motion.md](aspect-and-motion.md). For which case a verb governs, see [valency-and-prepositions.md](valency-and-prepositions.md).

The infinitive does not always predict the present tense. For any verb you are unsure of, establish four forms before writing: **infinitive, 1sg present, 3pl present, past masculine**, e.g. `niesť – nesiem – nesú – niesol`.

## 1. Present tense by theme vowel

The 3sg and 3pl forms identify the class. Endings: `-m, -š, —, -me, -te, 3pl` (the `-m` of 1sg is universal).

| Theme (3sg / 3pl)      | Model      | Forms                                                       | Same pattern                                                                   |
| ---------------------- | ---------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `-á` / `-ajú`          | `volať`    | volám, voláš, volá, voláme, voláte, volajú                  | `čakať, hľadať, poznať, dať (dám), mať (mám), hrať (hrám)`                     |
| same, long stem        | `čítať`    | čítam, čítaš, číta, čítame, čítate, čítajú                  | `bývať, spievať, plávať, počúvať` (rhythmic law shortens the `-á-`)            |
| `-ie` / `-ejú`         | `rozumieť` | rozumiem, rozumieš, rozumie, rozumieme, rozumiete, rozumejú | `vedieť` has `viem … vedia`; `smieť` has `smiem … smú`                         |
| `-í` / `-ia`           | `robiť`    | robím, robíš, robí, robíme, robíte, robia                   | `hovoriť, platiť, učiť, variť, cítiť, chváliť (chvália)`                       |
| `-í` / `-ia` (`-ieť`)  | `vidieť`   | vidím, vidíš, vidí, vidíme, vidíte, vidia                   | `sedieť, myslieť, musieť, letieť, bolieť`                                      |
| `-í` / `-ia` (`-ať`)   | `kričať`   | kričím, kričíš, kričí, kričíme, kričíte, kričia             | `držať, bežať, ležať, spať (spím, spia)`                                       |
| `-í` / `-a` after `j`  | `stáť`     | stojím, stojíš, stojí, stojíme, stojíte, stoja              | `báť sa (bojím sa, boja sa)`                                                   |
| `-ie` / `-ú`           | `niesť`    | nesiem, nesieš, nesie, nesieme, nesiete, nesú               | `viezť (veziem), viesť (vediem), piecť (pečiem, pečú), rásť (rastiem)`         |
| `-ie` / `-ú`           | `brať`     | beriem, berieš, berie, berieme, beriete, berú               | `zobrať (zoberiem), hnať (ženiem, ženú)`                                       |
| `-e` / `-ú` (`-u`)     | `písať`    | píšem, píšeš, píše, píšeme, píšete, píšu                    | `česať (češem, češú), plakať (plačem), ukázať (ukážem), poslať (pošlem)`       |
| `-ie` / `-ú` (`-núť`)  | `hynúť`    | hyniem, hynieš, hynie, hynieme, hyniete, hynú               | vowel before `-núť`: `minúť (miniem)`                                          |
| `-e` / `-ú` (`-núť`)   | `chudnúť`  | chudnem, chudneš, chudne, chudneme, chudnete, chudnú        | consonant before `-núť`: `zabudnúť, stretnúť, sadnúť si, padnúť`               |
| `-ne` / `-nú`          | `začať`    | začnem, začneš, začne, začneme, začnete, začnú              | `žať (žnem), stať sa (stanem sa), zostať (zostanem)`                           |
| `-ie` / `-ú` (`-rieť`) | `zavrieť`  | zavriem, zavrieš, zavrie, zavrieme, zavriete, zavrú         | `trieť, umrieť, zomrieť`                                                       |
| `-uje` / `-ujú`        | `pracovať` | pracujem, pracuješ, pracuje, pracujeme, pracujete, pracujú  | `kupovať, ďakovať, potrebovať, študovať, cestovať, žuť (žujem), obuť (obujem)` |
| `-je` / `-jú`          | `piť`      | pijem, piješ, pije, pijeme, pijete, pijú                    | `žiť, biť, kryť (kryjem), umyť (umyjem), smiať sa (smejem sa), siať (sejem)`   |

Whether the present has `-ie-` (`nesiem`, `beriem`) or `-e-` (`češem`, `píšem`, `chudnem`) depends on the class, not on syllable length. The rhythmic law does shape the 3pl: `-ú` after a short syllable (`nesú`, `češú`) but `-u` after a long one (`píšu`). 3pl `-ia` stays even after a long syllable (`chvália`, `súdia`), a recognized exception.

### Irregular verbs to know by heart

| `ísť`     | idem, ideš, ide, ideme, idete, idú               | išiel / išla              | choď, choďte     |
| `jesť`    | jem, ješ, je, jeme, jete, jedia                  | jedol / jedla             | jedz, jedzte     |
| `vedieť`  | viem, vieš, vie, vieme, viete, vedia             | vedel / vedela            | vedz, vedzte     |
| `chcieť`  | chcem, chceš, chce, chceme, chcete, chcú         | chcel / chcela            | —                |
| `môcť`    | môžem, môžeš, môže, môžeme, môžete, môžu         | mohol / mohla             | —                |
| `povedať` | poviem, povieš, povie, povieme, poviete, povedia | povedal / povedala        | povedz, povedzte |
| `vziať`   | vezmem, vezmeš, vezme, vezmeme, vezmete, vezmú   | vzal / vzala              | vezmi, vezmite   |
| `pomôcť`  | pomôžem, pomôžeš, pomôže … pomôžu                | pomohol / pomohla         | pomôž, pomôžte   |
| `obliecť` | oblečiem, oblečieš, oblečie … oblečú             | obliekol / obliekla       | obleč, oblečte   |
| `prísť`   | prídem, prídeš, príde … prídu                    | prišiel / prišla          | príď, príďte     |
| `nájsť`   | nájdem, nájdeš, nájde … nájdu                    | našiel / našla            | nájdi, nájdite   |
| `počuť`   | počujem, počuješ, počuje … počujú                | počul / počula            | počuj, počujte   |
| `dať`     | dám, dáš, dá, dáme, dáte, dajú                   | dal / dala                | daj, dajte       |

The 1pl `môžeme` is standard; `môžme` is colloquial at best (some guides call it non-standard).

## 2. Past tense

Form: l-participle agreeing with the subject + present `byť` as a clitic in the 1st and 2nd person. No auxiliary in the 3rd person.

```text
robil som / robila som        robili sme
robil si / robila si          robili ste
robil / robila / robilo       robili
```

### Building the l-participle

| Infinitive type                       | Rule                     | Examples                                                                                                                                                             |
| ------------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| vowel + `-ť`                          | replace `-ť` with `-l`   | `volať → volal`, `robiť → robil`, `pracovať → pracoval`, `piť → pil`                                                                                                 |
| `-ieť`                                | `-el`                    | `vidieť → videl`, `rozumieť → rozumel`, `chcieť → chcel`, `myslieť → myslel`                                                                                         |
| vowel + `-núť`                        | `-nul`                   | `minúť → minul`, `hynúť → hynul`                                                                                                                                     |
| consonant + `-núť`                    | `-ol`, feminine `-la`    | `zabudnúť → zabudol, zabudla`, `sadnúť → sadol`, `stretnúť → stretol`, `rozhodnúť → rozhodol`; exceptions `usnúť → usnul`, `hnúť → hnul`; `starnúť → starol/starnul` |
| consonant stems (`-sť`, `-zť`, `-cť`) | stem consonant + `-ol`   | `niesť → niesol`, `viezť → viezol`, `viesť → viedol`, `rásť → rástol`, `piecť → piekol`, `môcť → mohol`, `jesť → jedol`                                              |
| `-rieť`                               | `-rel`                   | `zavrieť → zavrel`, `umrieť → umrel`                                                                                                                                 |
| `ísť` and compounds                   | `-šiel`, feminine `-šla` | `išiel`, `prišiel`, `odišiel`, `našiel`, `vyšiel`                                                                                                                    |

Formal `vy` addressing one person takes a plural participle but a singular adjective: `Boli ste spokojný/spokojná?` `Kde ste boli?`

Clitic clusters: 2sg auxiliary `si` + reflexive gives `si sa` or `si si`: `Kde si sa narodil?` `Kúpil si si lístok?` Both words are needed.

## 3. Future tense

| Verb type                | Future                                                                           |
| ------------------------ | -------------------------------------------------------------------------------- |
| `byť`                    | budem, budeš, bude, budeme, budete, budú                                         |
| imperfective             | `budem` + infinitive: `budem pracovať`, `budeme čakať`                           |
| perfective               | present form = future: `napíšem`, `zavolám`, `prídem`                            |
| determinate motion verbs | prefix `po-`: `pôjdem`, `pobežím`, `poletím`, `ponesiem`, `poveziem`, `povediem` |

Never combine `budem` with a perfective (`*budem napísať`). Use `pôjdem` for "I will go"; `budem ísť` is not standard. Other determinate motion verbs allow both: `pobežím` / `budem bežať`, `ponesiem` / `budem niesť`.

## 4. Conditional

Form: l-participle + `by` + the present `byť` clitic. `by` is itself a second-position clitic.

```text
robil by som / robila by som     robili by sme
robil by si                      robili by ste
robil by                         robili by
Rád by som šiel.  Mohli by ste mi pomôcť?  Čo by si robil?
```

In `aby` and `keby` the `by` is already part of the conjunction: `keby som mal čas`, `aby si prišiel`, `keby sme vedeli`. Past conditional (`bol by som prišiel`) is formal; see [advanced-forms-and-usage.md](advanced-forms-and-usage.md) §6.

## 5. Imperative

Start from the 3pl present, remove the ending, then:

| Stem after removing the ending           | 2sg          | Examples                                                                                                                                     |
| ---------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| ends in a vowel + `j` (not `ij`, `yj`)   | as is        | `čítajú → čítaj`, `volajú → volaj`, `pracujú → pracuj`, `počúvajú → počúvaj`                                                                 |
| ends in one consonant                    | as is        | `robia → rob`, `píšu → píš`, `nesú → nes`, `berú → ber`, `kúpia → kúp`                                                                       |
| final `t, d, n, l` → soft                | `ť, ď, ň, ľ` | `platia → plať`, `vrátia → vráť`, `sedia → seď`, `letia → leť`, `zostanú → zostaň`                                                           |
| ends in `ij`/`yj`                        | drop the `j` | `pijú → pi`, `žijú → ži`, `bijú → bi`, `umyjú → umy`, `kryjú → kry`                                                                          |
| ends in a consonant cluster, or no vowel | add `-i`     | `spia → spi`, `myslia → mysli`, `čistia → čisti`, `pustia → pusti`, `sadnú si → sadni si`, `začnú → začni`, `pošlú → pošli`, `zavrú → zavri` |

1pl adds `-me`, 2pl adds `-te` to the 2sg: `rob – robme – robte`, `spi – spime – spite`, `plať – plaťme – plaťte`.

Suppletive or irregular: `ísť → choď` (go), `poď` (come here / let's go: `Poďme!`), `byť → buď`, `jesť → jedz`, `vedieť → vedz`, `povedať → povedz`, `vziať → vezmi`, `stáť → stoj`, `báť sa → neboj sa`.

Third person and wishes: `nech` + present: `Nech príde.` `Nech sa páči.` `Nech sa ti darí.`

Negation and aspect in the imperative are covered in [aspect-and-motion.md](aspect-and-motion.md) §3.

## 6. Negation

`ne-` is written together with the verb: `nerobím`, `nebol som`, `nebudem`, `nechcel by som`, `nechoď`.

The present of `byť` is the exception: **`nie som, nie si, nie je, nie sme, nie ste, nie sú`** are written as two words. Past and future join again: `nebol`, `nebude`.

## 7. Participles, transgressives, verbal nouns

### Passive participle (`-ný`, `-tý`)

| Infinitive      | Participle | Examples                                                                                                                    |
| --------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| `-ať`           | `-aný`     | `napísať → napísaný`, `poslať → poslaný`, `zavolať → zavolaný`, `dať → daný`                                                |
| `-ovať`         | `-ovaný`   | `zorganizovať → zorganizovaný`, `kupovať → kupovaný`                                                                        |
| `-iť`, `-ieť`   | `-ený`     | `urobiť → urobený`, `kúpiť → kúpený`, `zaplatiť → zaplatený`, `vyhodiť → vyhodený`, `vidieť → videný`, `otvoriť → otvorený` |
| consonant stems | `-ený`     | `priniesť → prinesený`, `nájsť → nájdený`, `upiecť → upečený`, `obliecť → oblečený`                                         |
| `-núť`          | `-nutý`    | `zabudnúť → zabudnutý`, `minúť → minutý`                                                                                    |
| short stems     | `-tý`      | `piť → pitý`, `umyť → umytý`, `zavrieť → zavretý`, `začať → začatý`, `vziať → vzatý`                                        |

Slovak keeps the stem consonant where Czech alternates: `vyhodený` (not `*vyhozený`), `zaplatený` (not `*zaplacený`).

### Present active participle (`-úci`, `-iaci`)

3pl + `-ci`: `robia → robiaci`, `nesú → nesúci`, `pracujú → pracujúci`, `čítajú → čítajúci`, `spia → spiaci`; after a long syllable `-uci`: `píšu → píšuci`. Declines like `cudzí` but with short endings: `robiaca, robiace, robiaceho` (not `*robiacia`). Many are lexicalized nouns: `cestujúci` (passenger), `vedúci` (manager), `pracujúci`.

### Transgressive (`-úc`, `-iac`)

`idúc`, `nesúc`, `robiac`, `píšuc`, `vediac`, `sediac`. Formal or literary only; set off with commas. `vediac, že ...` survives in formal writing.

### Verbal noun (`-nie`, `-tie`)

Built on the passive participle stem: `písať → písanie`, `čítať → čítanie`, `robiť → robenie`, `fajčiť → fajčenie`, `piť → pitie`, `začať → začatie`, `otvoriť → otvorenie`. Neuter, `vysvedčenie` declension. Aspect matters: `čítanie` (reading) vs. `prečítanie` (having read through).

## 8. Dictionary and table checklist

When presenting a verb to learners or in a form table:

1. Give infinitive + aspect + partner: `písať (ipf.) / napísať (pf.)`.
2. Give 1sg and 3pl present; they identify the class.
3. Give past masculine and feminine if the l-participle is not regular (`niesol, niesla`).
4. Give the imperative if it is irregular or adds `-i`.
5. Include `sa`/`si` and the governed case: `báť sa + gen.`, `pomáhať + dat.`
