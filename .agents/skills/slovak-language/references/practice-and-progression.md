# Practice and Progression

Use this as the practical layer for task types, answer criteria, and progression—not a timetable to follow blindly.

## Build a practice cycle

For every target, use this order:

1. **Notice:** identify the form in a short meaningful sentence.
2. **Control:** choose or inflect one form.
3. **Contrast:** change one variable that forces a different form.
4. **Personalize:** say/write a true sentence about the learner.
5. **Communicate:** complete a timed mini-task without prompts.
6. **Retrieve later:** revisit after 1, 3, 7, and 14 days.

Do not count passive recognition as mastery. A learner who selects `v škole` but cannot say `Zajtra idem do školy` has not mastered the location/destination contrast.

## Phonology practice

### Vowel length and stress

Read pairs slowly, then in sentences: `rad/rád`, `sud/súd`, `mala/malá`, `pas/pás`. Mark first-syllable stress, then record an 8-10 word sentence. Judge length before speed.

### Softness and clusters

Use small sets that contrast a hard and a soft onset: `tam – ťahať`, `dom – ďakujem`, `nos – ňou`, `lano – ľan`; then real words `deti, ticho, nikdy, ľudia, ďakujem, päť`. For clusters: `štvrť, krk, vlk, zmrzlina, Bratislava`. Do not add English schwa vowels.

### Minimal speaking check

Ask learner to say: `V piatok ráno idem vlakom do Košíc.` Check: first-syllable stress on every word, the diphthong in `piatok`, long vowels in `ráno` and `Košíc`, destination `do Košíc`, and no deleted consonants.

## Grammar drill families

### Gender and agreement

Give base noun + adjective; learner creates three forms:

```text
nový / dom       → nový dom, vidím nový dom, s novým domom
dobrý / učiteľ   → dobrý učiteľ, vidím dobrého učiteľa, s dobrým učiteľom
pekná / ulica    → pekná ulica, vidím peknú ulicu, na peknej ulici
veľké / mesto    → veľké mesto, do veľkého mesta, vo veľkom meste
```

Score separately: gender, case ending, adjective agreement, preposition. Correct the first broken link, not every related form at once.

### Case transformation grid

Give `hotel` or `kaviareň`; require:

| Meaning                | Expected frame                           |
| ---------------------- | ---------------------------------------- |
| I see it               | `vidím + acc.`                           |
| I go there             | `do + gen.` / `na + acc.` as appropriate |
| I am there             | `v + loc.` / `na + loc.`                 |
| I am with it/person    | `s/so + instr.`                          |
| I talk about it/person | `o + loc.`                               |
| I need/help/wait       | verb-governed case                       |

Use map, shopping, health, and work contexts so endings do not become a detached table.

### Aspect drill

Give a situation, not English tense alone.

```text
You spent an hour writing and did not finish. → Písal/a som list.
You completed it and sent it.                → Napísal/a som list a poslal/a som ho.
You buy coffee habitually.                   → Kupujem si kávu.
You buy one coffee now.                      → Kúpim si kávu.
```

Require learner to state _why_ form is imperfective/perfective: process/habit vs bounded result. Reject a correct-looking prefix that changes intended meaning.

### Clitic placement

Reorder words into natural Slovak:

```text
včera / som / mu / to / povedal → Včera som mu to povedal.
tá kniha / sa / mi / páči       → Tá kniha sa mi páči.
keď / som / prišiel / tam        → Keď som tam prišiel ...
```

Then make a contrastive version: `Povedal to mne, nie jej.` Explain why full pronoun moves when stressed.

## Functional task bank

### A1 survival tasks

- Introduce yourself, origin, languages, and one reason for learning Slovak.
- Ask and answer three questions about time, transport, and price.
- Order a drink/meal with a dietary change: `bez ...`, `s ...`, `prosím si ...`.
- Describe a room; then tell someone where to put three objects.

Success: comprehensible, correct core frame, no `ty/vy` mismatch. Ignore non-blocking lexical gaps first.

### A2 independent-life tasks

- Leave a voicemail: name, reason, request for callback, availability.
- Explain a doctor problem: symptom, duration, medication, request.
- Tell a travel failure in 6-8 sentences, with at least two aspect pairs.
- Write a 90-word invitation or apology, including time/place and response request.

Success: past/future distinction, appropriate politeness, connected sentences, core cases correct.

### B1 work/public tasks

- Compare two flats or jobs; make recommendation with two reasons and one concession.
- Write a service complaint: issue, dates/facts, requested remedy, polite close.
- Summarize a short cultural event, then recommend/not recommend it.
- Describe a change in town/family/work over time using aspect and connectors.

### B2 analytic tasks

- Write a balanced 180-250 word argument on a media/environment/work topic.
- Convert a conversational account into neutral professional summary.
- Present a historical/cultural topic: event, context, consequence, qualified interpretation.
- Debate migration, technology, or public services; state a counterargument fairly before responding.

## Four-skill assessment rubric

| Skill     | What to test                          | What counts as pass                                                           |
| --------- | ------------------------------------- | ----------------------------------------------------------------------------- |
| listening | slow learner audio → natural speech   | identify gist, key facts, speaker stance, then infer one unstated relation    |
| speaking  | role-play + 1-3 minute monologue      | understandable flow; repairs; grammar adequate for task; register fits        |
| reading   | message, notice, article, formal text | locate fact, infer purpose, distinguish opinion/fact, summarize               |
| writing   | message → email → argument            | task met, coherent structure, correct high-frequency forms, revision evidence |

Track errors by category: `case frame`, `agreement`, `aspect`, `verb form`, `word order/clitic`, `orthography`, `register`, `lexis`. For each recurring error, store one corrected personal sentence and one future retrieval prompt.

## Vocabulary retention by theme

Make cards as **frame + word + output**, not translation only:

```text
do + genitive: Idem do ___           → práce / školy / mesta
wait for: Čakám na ___               → autobus / odpoveď / lekára
interested in: Zaujímam sa o ___     → hudbu / históriu / šport
with: Idem s ___                     → kamarátom / rodinou / kolegyňou
```

Cycle domains: people/home; food/shopping; places/travel; time/routine; health; work/study; culture/media; public topics. Require 10 new frames or chunks to appear in a voice/writing task each week.

## Self-correction protocol

Before submitting Slovak, run:

1. Have I chosen `ty` or `vy` consistently?
2. Does every location/destination phrase use the intended case?
3. Does every past form match speaker/subject gender and number?
4. Does each perfective verb mean a completed/one-off result here?
5. Are clitics in second position and are diacritics present?
6. Can one sentence be made more direct and less English-shaped?

For spoken work, add: Can I repair? `Prepáčte, poviem to ešte raz.` `Myslel/a som ...` `Ako sa povie ...?`
