# Foundations and Core Communication

Use this for beginner and lower-intermediate Slovak: teach, translate, correct, or make exercises. It is a practical language reference, not a lesson-title list.

## First interaction and identity

Use `Dobrý deň` as safe default. `Ahoj` fits friends, children, and people already using `ty`. Core exchange:

```text
Dobrý deň. Volám sa Anna Nováková.
Teší ma. Ja som Peter.
Odkiaľ ste? Som z Kanady, ale bývam v Bratislave.
Hovoríte po slovensky? Trochu. Ešte sa učím.
```

`volať sa` uses `sa`: `Volám sa ...`, `Ako sa voláš?`, `Ako sa voláte?`. Do not say an English-shaped _`Moje meno je`_ unless deliberately emphatic. `Som` serves identity, nationality, and profession: `Som študentka. Som Slovenka. Som z Anglicka.` Use the gender form when relevant: `Slovák/Slovenka`, `Američan/Američanka`, `unavený/unavená`.

`ty` = one familiar person; `vy` = plural or formal singular. Formal verb is plural: `Máte chvíľu?`, `Ste pripravený/pripravená?` Keep the agreement singular in an individual formal addressee but verbs plural.

## Gender, agreement, and usable noun frames

Gender is not decoration; it drives the rest of the clause. Start with forms learners can reuse:

| Noun                       | Pattern                            | Use                          |
| -------------------------- | ---------------------------------- | ---------------------------- |
| `stôl` masculine inanimate | `nový stôl – na stole – so stolom` | object/location/with         |
| `muž` masculine animate    | `dobrý muž – vidím dobrého muža`   | animate accusative           |
| `žena` feminine            | `dobrá žena – so ženou`            | feminine `-a`                |
| `ulica` feminine           | `dlhá ulica – na ulici`            | feminine soft-ish pattern    |
| `mesto` neuter             | `veľké mesto – do mesta – v meste` | destination/location         |
| `dievča` neuter            | `malé dievča – s dievčaťom`        | special neuter child pattern |

Adjective order is normally before the noun: `nový byt`, `nová izba`, `nové auto`. Predicate adjective agrees: `Byt je nový. Izba je nová. Auto je nové.` Past tense agrees too: `Peter bol doma. Jana bola doma. Deti boli doma.`

## Present tense: use, not just tables

Most daily talk needs a small core of predictable classes plus irregulars.

```text
pracovať: pracujem, pracuješ, pracuje, pracujeme, pracujete, pracujú
robiť: robím, robíš, robí, robíme, robíte, robia
čítať: čítam, čítaš, číta, čítame, čítate, čítajú
kupovať: kupujem, kupuješ, kupuje, kupujeme, kupujete, kupujú
```

High-frequency irregular forms: `som/si/je/sme/ste/sú`; `mám/máš/má/máme/máte/majú`; `idem/ideš/ide`; `chcem/chceš/chce`; `viem/vieš/vie`; `môžem/môžeš/môže`; `musím/musíš/musí`; `jem/ješ/je`; `pijem/piješ/pije`.

Subjects usually disappear: `Pracujem v meste.` not necessarily `Ja pracujem...`. Add pronouns for contrast: `Ja pracujem dnes, ty pracuješ zajtra.` Ask yes/no questions with intonation: `Pracuješ dnes?`; use `čo, kto, kde, kam, odkiaľ, kedy, prečo, ako, koľko` for information.

## Wanting, liking, ability, obligation

These patterns drive A1-A2 production:

| Meaning              | Form                           | Example                       |
| -------------------- | ------------------------------ | ----------------------------- |
| want to              | `chcieť + infinitive`          | `Chcem ísť domov.`            |
| can / permitted      | `môcť + infinitive`            | `Môžem tu sedieť?`            |
| know how / know fact | `vedieť + infinitive / clause` | `Viem variť. Viem, že príde.` |
| must                 | `musieť + infinitive`          | `Musíme odísť.`               |
| like                 | `mať rád/rada + acc.`          | `Mám rada kávu.`              |
| be pleasing          | `páčiť sa + dat.`              | `Páči sa mi tá kniha.`        |
| would like           | `chcieť` conditional           | `Chcel by som čaj.`           |

`Mám rád` agrees with the liker, not thing liked: male `mám rád`, female `mám rada`, plural masculine animate `máme radi`, other plural `máme rady`.

## Core case system in situations

Teach case as meaning. The same noun moves with the situation:

```text
Bratislava je veľké mesto.             nominative
Vidím Bratislavu.                      accusative
Idem do Bratislavy.                    do + genitive: destination
Bývam v Bratislave.                    v + locative: location
Pomáham kamarátovi.                    dative: recipient/beneficiary
Idem s kamarátom.                      instrumental: accompaniment
Hovorím o kamarátovi.                  locative: topic
```

High-value destination/location pairs: `do školy / v škole`, `do mesta / v meste`, `na stanicu / na stanici`, `do reštaurácie / v reštaurácii`, `na stôl / na stole`, `k lekárovi / u lekára`.

Use object cases in natural chunks: `mám čas`, `hľadám hotel`, `čakám na autobus`, `vidím dobrého učiteľa`, `potrebujem pomoc`, `pomáham mame`, `verím ti`, `bojím sa psa`, `bez cukru`, `s mliekom`.

## Food, shopping, and service language

```text
Prosím si kávu bez cukru.
Čo si prajete? Dám si polievku a minerálku.
Máte vegetariánske jedlo?
Koľko to stojí? Môžem platiť kartou?
Účet, prosím. Ďakujem pekne.
```

Quantity: `jedna káva`, `dve kávy`, `tri kávy`, `štyri kávy`, `päť káv`; `kilo jabĺk`, `liter mlieka`, `šálka čaju`, `pohár vody`, `kus chleba`. After `päť` and higher, use genitive plural; learn measure expressions as complete phrases.

Shopping correction patterns: `Hľadám ...`; `Máte ...?`; `Chcel/a by som vymeniť ...`; `Je to príliš drahé.`; `Potrebujem menšiu/väčšiu veľkosť.`

## Time, date, routine, weather

```text
Koľko je hodín? Je jedna hodina. Sú dve hodiny. Je päť hodín.
Stretneme sa o tretej. O pol tretej. O štvrť na tri.
Dnes je pondelok. V pondelok pracujem. V januári často sneží.
Včera pršalo. Dnes je zamračené, ale teplo.
```

Routine takes imperfective: `Vstávam o siedmej, raňajkujem, potom chodím do práce.` For a specific completed day, use past/perfective as needed: `Včera som vstal/a o siedmej a išiel/išla som do práce.`

## Past, future, and aspect in practice

Past = l-participle + clitic: `čítal som`, `čítala som`, `čítali sme`; third person omits auxiliary: `Čítal knihu. Čítali noviny.`

Imperfective frames an activity/habit: `Písal som list.`, `Každý deň chodím pešo.` Perfective frames a completed result: `Napísal som list.`, `Prišiel som domov.` Use pairs in contrast, never as simple English past equivalents.

```text
Včera som písal list. Ešte nebol hotový.
Večer som list napísal a poslal.
Zajtra budem písať ďalší list.
Zajtra napíšem ďalší list.     (one completed planned result)
```

Future: `budem + infinitive` for imperfective (`budem pracovať`); perfective present is future (`kúpim, prídem, napíšem`). `ísť` future is `pôjdem`.

## Reflexives, imperative, and polite requests

`sa` belongs to many verbs: `volať sa, učiť sa, báť sa, stretnúť sa, páčiť sa`. `si` is commonly dative/self-benefit: `kúpim si kávu`, `umyjem si ruky`, `oblečiem si kabát`.

Imperative: `Poď!`, `Poďte!`, `Počkajte!`, `Sadnite si!`, `Povedzte mi to.`, `Zapíšte si adresu.`, `Nebojte sa.` Soften direct orders in service contexts: `Mohli by ste ...?`, `Prosím vás, ...`, `Chcel/a by som ...`.

## A2: connected speech and writing

Connect thoughts: `a, ale, alebo, pretože, lebo, preto, takže, keď, ak, keby, aby, hoci`. Build a short story: time → event → reason → result → reaction.

```text
Včera som zmeškal vlak, pretože autobus meškal.
Keď som prišiel na stanicu, vlak už odišiel.
Nakoniec som išiel domov taxíkom, ale stálo to veľa peňazí.
```

Email shape: greeting; reason; concrete request/information; closing. `Dobrý deň, píšem Vám kvôli ... Prosím Vás o ... Ďakujem za odpoveď. S pozdravom ...` Informal: `Ahoj, ako sa máš? ... Maj sa.`

## Practice loop

For each target, require four outputs: choose form, transform location/destination, say a personal sentence, write/record a mini-dialogue. Example for `do/v`:

1. Complete: `Zajtra idem ___ školy, dnes som ___ škole.`
2. Transform: `Kniha je na stole → Položím knihu ...`
3. Personalize: say three places you go and three places you are.
4. Role-play: ask how to get to a pharmacy, then explain the route.

Correct by naming the frame: `do + genitive` not “wrong ending.” Recycle the same frame later with travel, work, health, and culture vocabulary.
