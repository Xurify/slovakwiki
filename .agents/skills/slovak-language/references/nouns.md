# Nouns: Declension Paradigms and Traps

Use this when you need a correct noun form: tables for lessons, cloze answers, corrections, or any phrase where the case is not obvious. Learn the model noun, then the exceptions that actually catch people.

Slovak has six cases (N, G, D, A, L, I), two numbers, and four genders: masculine animate, masculine inanimate, feminine, neuter. The vocative is not a full case in modern Slovak (see [advanced-forms-and-usage.md](advanced-forms-and-usage.md) §9).

## 1. How to identify the model

| Nominative singular ends in…                      | Gender (usual)      | Model            |
| ------------------------------------------------- | ------------------- | ---------------- |
| consonant, person or animal                       | masculine animate   | `chlap`          |
| `-a`, male person (`hrdina`, `kolega`, `turista`) | masculine animate   | `hrdina`         |
| hard consonant, thing                             | masculine inanimate | `dub`            |
| soft consonant (`-j`, `-č`, `-c`, `-ľ`…), thing   | masculine inanimate | `stroj`          |
| `-a` after a hard consonant                       | feminine            | `žena`           |
| `-a` after a soft consonant, `-ia`                | feminine            | `ulica`          |
| soft consonant (`-ň`, `-ť`, `-ď`, `-c`, `-č`…)    | feminine            | `dlaň` or `kosť` |
| `-o`                                              | neuter              | `mesto`          |
| `-e`                                              | neuter              | `srdce`          |
| `-ie`                                             | neuter              | `vysvedčenie`    |
| `-a`/`-ä` for young beings (`dievča`, `žriebä`)   | neuter              | `dievča`         |

The final consonant does not reveal the gender: `stôl` and `deň` are masculine; `kosť`, `dlaň`, and `jeseň` are feminine. When unsure, check the genitive singular in a dictionary (`kosť → kosti` feminine, `hosť → hosťa` masculine).

## 2. Masculine animate

| Case | `chlap` sg. | `chlap` pl. | `hrdina` sg. | `hrdina` pl. |
| ---- | ----------- | ----------- | ------------ | ------------ |
| N    | chlap       | chlapi      | hrdina       | hrdinovia    |
| G    | chlapa      | chlapov     | hrdinu       | hrdinov      |
| D    | chlapovi    | chlapom     | hrdinovi     | hrdinom      |
| A    | chlapa      | chlapov     | hrdinu       | hrdinov      |
| L    | chlapovi    | chlapoch    | hrdinovi     | hrdinoch     |
| I    | chlapom     | chlapmi     | hrdinom      | hrdinami     |

Rules worth teaching:

- **Accusative = genitive** for masculine animates in the singular, and in the plural for male persons only (animals: see below): `Vidím brata.` `Poznám tých študentov.`
- **Dative and locative singular end in `-ovi`**: `bratovi`, `o učiteľovi`. Exceptions: `človek → človeku`, `Boh → Bohu`.
- **Instrumental plural** is usually `-mi` (`chlapmi`, `mužmi`, `učiteľmi`); the `hrdina` type and some others take `-ami` (`hrdinami`, `kolegami`, `hosťami`).

### Nominative plural: four patterns

| Ending     | Typical nouns                               | Examples                                                                                    |
| ---------- | ------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `-i`       | most consonant-final nouns                  | `študenti`, `muži`, `kamaráti`, `lekári`, `páni`                                            |
| `-ovia`    | `-a`/`-o` nouns, many kinship terms, `-lóg` | `kolegovia`, `dedovia`, `synovia`, `otcovia`, `biológovia`                                  |
| `-ia`      | `-teľ`, `-an`, and a closed set             | `učitelia`, `priatelia`, `občania`, `Angličania`, `bratia`, `susedia`, `hostia`, `manželia` |
| suppletive | —                                           | `človek → ľudia`                                                                            |

Consonant changes before `-i`: `k → c` (`Slovák → Slováci`, `vojak → vojaci`), `ch → s` (`Čech → Česi`). The `-ec` nouns drop the `e` (`chlapec → chlapci`). `-teľ → -telia` loses the softness mark: `učiteľ → učitelia`.

Plural agreement: masculine-person plurals take `-í/-i` adjectives and pronouns: `tí noví kolegovia`, `všetci študenti`. Mixed groups use the same forms.

### Animals

Animal nouns are animate in the singular (`Vidím psa.`) but take inanimate-style forms in the nominative and accusative plural: `psy`, `vtáky`, `kone`; `Vidím psy.`

### Irregular and high-frequency animates

| Noun     | Forms to know                                                                                         |
| -------- | ----------------------------------------------------------------------------------------------------- |
| `človek` | sg. `človeka, človeku, človeka, o človeku, človekom`; pl. `ľudia, ľudí, ľuďom, ľudí, o ľuďoch, ľuďmi` |
| `brat`   | pl. `bratia, bratov, bratom, bratov, o bratoch, bratmi`                                               |
| `hosť`   | sg. `hosťa`; pl. `hostia, hostí, hosťom, hostí, o hosťoch, hosťami`                                   |
| `otec`   | `otca, otcovi`; pl. `otcovia` (the `e` drops)                                                         |
| `pán`    | `pána, pánovi`; pl. `páni`; vocative `pane`                                                           |
| `pes`    | `psa, psovi, psom`; pl. `psy, psov`                                                                   |

## 3. Masculine inanimate

| Case | `dub` sg. | `dub` pl. | `stroj` sg. | `stroj` pl. |
| ---- | --------- | --------- | ----------- | ----------- |
| N    | dub       | duby      | stroj       | stroje      |
| G    | duba      | dubov     | stroja      | strojov     |
| D    | dubu      | dubom     | stroju      | strojom     |
| A    | dub       | duby      | stroj       | stroje      |
| L    | dube      | duboch    | stroji      | strojoch    |
| I    | dubom     | dubmi     | strojom     | strojmi     |

### Genitive singular `-a` or `-u` is lexical

No rule predicts it reliably; record it with the noun.

| `-a`                                                                                                                                                             | `-u`                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stôl → stola`, `les → lesa`, `rok → roka`, `deň → dňa`, `syr → syra`, `chlieb → chleba`, `jazyk → jazyka`, `svet → sveta`, `život → života`, `papier → papiera` | `dom → domu`, `čas → času`, `obchod → obchodu`, `vlak → vlaku`, `hrad → hradu`, `čaj → čaju`, `film → filmu`, `problém → problému`, `park → parku`, `cukor → cukru` |

### Locative singular `-e`, `-u`, or `-i`

| Ending | When                                                                      | Examples                                                                   |
| ------ | ------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| `-e`   | default for hard stems, including loans                                   | `v dome`, `na stole`, `v obchode`, `vo filme`, `na koncerte`               |
| `-u`   | stems ending in `k`, `g`, `h`, `ch`                                       | `vo vlaku`, `v parku`, `v roku`, `na trhu`                                 |
| `-i`   | soft stems; many nouns in `-r`/`-l` (`-ár`, `-ier`, `-ber`, `-el`, `-ál`) | `v stroji`, `v kraji`, `v pohári`, `na papieri`, `v hoteli`, `v septembri` |

The `-i` group for `-r`/`-l` nouns has exceptions (`v kostole`); verify any form you have not seen.

### Stem changes

- **Mobile vowel drops** outside the nominative singular. The drop is lexical; high-value cases: `deň → dňa`, `týždeň → týždňa`, `otec → otca`, `chlapec → chlapca`, `pes → psa`, `sen → sna`, `cukor → cukru`, `vietor → vetra`, `lístok → lístka`, and the names `Peter → Petra`, `Pavol → Pavla`, `Karol → Karla`.
- **A long vowel shortens**: `stôl → stola`, `kôň → koňa`, `nôž → noža`, `chlieb → chleba`, `vietor → vetra`.

### Days, months, and time words

`deň`: sg. `deň, dňa, dňu, deň, (o) dni, dňom` (the old locative `dne` survives only in `vo dne (v noci)`); pl. `dni, dní, dňom, dni, dňoch, dňami`. `týždeň → týždňa, v týždni`; pl. `týždne, týždňov`. `rok → roka, v roku`; pl. `roky`, and after numerals `päť rokov`. `mesiac → mesiaca`; pl. `mesiace, mesiacov`.

Time frames learners need constantly:

```text
v pondelok, v utorok, v stredu, vo štvrtok, v piatok, v sobotu, v nedeľu    (v + accusative)
v januári, vo februári, v marci, v apríli, v máji, v júni,
v júli, v auguste, v septembri, v októbri, v novembri, v decembri         (v + locative)
na jar, v lete, na jeseň, v zime
ráno, doobeda / dopoludnia, napoludnie, poobede / popoludní, večer, v noci
```

## 4. Feminine

| Case | `žena` sg. | `žena` pl. | `ulica` sg. | `ulica` pl. |
| ---- | ---------- | ---------- | ----------- | ----------- |
| N    | žena       | ženy       | ulica       | ulice       |
| G    | ženy       | žien       | ulice       | ulíc        |
| D    | žene       | ženám      | ulici       | uliciam     |
| A    | ženu       | ženy       | ulicu       | ulice       |
| L    | žene       | ženách     | ulici       | uliciach    |
| I    | ženou      | ženami     | ulicou      | ulicami     |

Nouns in `-ia` follow `ulica` with `-ii` in the dative/locative and `-ií` in the genitive plural: `reštaurácia → reštaurácie, v reštaurácii, s reštauráciou`, gen. pl. `reštaurácií`; likewise `kancelária`, `Mária`. Plain `-ica` nouns stay regular: `stanica → na stanici`, gen. pl. `staníc`.

| Case | `dlaň` sg. | `dlaň` pl. | `kosť` sg. | `kosť` pl. |
| ---- | ---------- | ---------- | ---------- | ---------- |
| N    | dlaň       | dlane      | kosť       | kosti      |
| G    | dlane      | dlaní      | kosti      | kostí      |
| D    | dlani      | dlaniam    | kosti      | kostiam    |
| A    | dlaň       | dlane      | kosť       | kosti      |
| L    | dlani      | dlaniach   | kosti      | kostiach   |
| I    | dlaňou     | dlaňami    | kosťou     | kosťami    |

Soft-consonant feminines split by the genitive singular:

- **`dlaň` type, genitive `-e`**: `lekáreň → lekárne`, `kaviareň → kaviarne`, `pieseň → piesne`, `báseň → básne`, `jeseň → jesene`, `posteľ → postele`, `tvár → tváre`.
- **`kosť` type, genitive `-i`**: every noun in `-osť` (`radosť → radosti`), plus `vec → veci`, `noc → noci`, `reč → reči`, `soľ → soli`, `chuť → chuti`.

### Genitive plural: zero ending, with compensation

Most `-a` feminines and `-o` neuters have no ending in the genitive plural. The stem compensates by lengthening a vowel or inserting one:

| Change                    | Feminine                                                               | Neuter                                                      |
| ------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------- |
| `e → ie`                  | `žena → žien`                                                          | `mesto → miest`, `leto → liet`                              |
| `i/y → í/ý`               | `kniha → kníh`, `chyba → chýb`, `ulica → ulíc`, `hodina → hodín`       | —                                                           |
| `o → ô`                   | `noha → nôh`, `škola → škôl`, `hora → hôr`                             | `kolo → kôl`                                                |
| syllabic `l → ĺ`, `r → ŕ` | —                                                                      | `jablko → jabĺk`, `zrno → zŕn`                              |
| `a → á`, `u → ú`          | `mama → mám`, `ruka → rúk`                                             | `auto → áut`                                                |
| inserted vowel            | `sestra → sestier`, `karta → kariet`, `izba → izieb`, `matka → matiek` | `okno → okien`, `číslo → čísel`                             |
| none: stem already long   | `chvíľa → chvíľ`, `lúka → lúk`, `minúta → minút`                       | `číslo → čísel` (long `í`, so the inserted `e` stays short) |

Rhythmic law: a stem that already has a long syllable does not lengthen again. Some nouns simply have no lengthening (`slovo → slov`). This table is where most generated errors live: check every genitive plural you are not sure of.

### Rhythmic law in case endings

After a long syllable, a long ending shortens: `ženám` but `lúkam`; `ženách` but `lúkach`; `uliciam` but `piesňam`, `básňam`. Do not produce `*lúkám`.

## 5. Neuter

| Case | `mesto` sg. | `mesto` pl. | `srdce` sg. | `srdce` pl. |
| ---- | ----------- | ----------- | ----------- | ----------- |
| N    | mesto       | mestá       | srdce       | srdcia      |
| G    | mesta       | miest       | srdca       | sŕdc        |
| D    | mestu       | mestám      | srdcu       | srdciam     |
| A    | mesto       | mestá       | srdce       | srdcia      |
| L    | meste       | mestách     | srdci       | srdciach    |
| I    | mestom      | mestami     | srdcom      | srdcami     |

| Case | `vysvedčenie` sg. | pl.           | `dievča` sg. | pl.        |
| ---- | ----------------- | ------------- | ------------ | ---------- |
| N    | vysvedčenie       | vysvedčenia   | dievča       | dievčatá   |
| G    | vysvedčenia       | vysvedčení    | dievčaťa     | dievčat    |
| D    | vysvedčeniu       | vysvedčeniam  | dievčaťu     | dievčatám  |
| A    | vysvedčenie       | vysvedčenia   | dievča       | dievčatá   |
| L    | vysvedčení        | vysvedčeniach | dievčati     | dievčatách |
| I    | vysvedčením       | vysvedčeniami | dievčaťom    | dievčatami |

- **Locative `-u` for velar stems**: `oko → v oku`, `jablko → v jablku`, `mlieko → v mlieku`, `ihrisko → na ihrisku`.
- **Countries in `-sko`/`-cko` take `-u`**: `na Slovensku`, `v Rakúsku`, `v Nemecku`, `v Česku`, `v Poľsku`, `v Maďarsku`, `v Rusku`. Never `*v Rakúske`.
- **`-um` loans** drop `-um` outside the nominative: `múzeum → múzea, v múzeu`, pl. `múzeá`; `centrum → centra, v centre`; `štúdium → štúdia, v štúdiu`.
- **`dieťa`**: sg. `dieťa, dieťaťa, dieťaťu, dieťa, o dieťati, dieťaťom`; pl. `deti, detí, deťom, deti, o deťoch, deťmi`. The plural agrees like a non-masculine-person plural: `malé deti`, `deti boli`.
- **`oko`, `ucho`** (body parts) have special plurals: `oči, očí, očiam, oči, očiach, očami`; `uši, uší, ušiam, uši, ušiach, ušami`.

## 6. Plural-only nouns

These have plural forms and plural agreement even for one item. Count them with `jedny, dvoje, troje`.

| Noun         | Genitive  | Note                         |
| ------------ | --------- | ---------------------------- |
| `nohavice`   | nohavíc   | `jedny nohavice`             |
| `dvere`      | dverí     | `Zatvor dvere.`              |
| `okuliare`   | okuliarov | `Kde mám okuliare?`          |
| `peniaze`    | peňazí    | D `peniazom`, I `peniazmi`   |
| `ústa`       | úst       |                              |
| `nožnice`    | nožníc    |                              |
| `hodinky`    | hodiniek  | wristwatch                   |
| `raňajky`    | raňajok   | `na raňajky`, `po raňajkách` |
| `narodeniny` | narodenín | `k narodeninám`              |
| `meniny`     | menín     | name day                     |
| `prázdniny`  | prázdnin  | school holidays              |
| `Vianoce`    | Vianoc    | `na Vianoce`, `cez Vianoce`  |
| `šaty`       | šiat      | dress; clothes               |

Plural place names behave the same way, and they are frequent in travel content:

```text
Košice     → do Košíc, v Košiciach, z Košíc
Michalovce → do Michaloviec, v Michalovciach
Piešťany   → do Piešťan, v Piešťanoch
Levice     → do Levíc, v Leviciach
Topoľčany  → do Topoľčian, v Topoľčanoch
```

`Košice sú na východe.` takes a plural verb, never `*Košice je`.

## 7. Indeclinable and loan nouns

A few loans do not decline: `taxi`, `menu`, `alibi`, `kupé`. They are neuter: `nové menu`, `v menu`. Most loans decline once they end in a Slovak-looking sound: `kakao → kakaa`, `rádio → rádia, v rádiu`, `kino → v kine`, `metro → v metre`.

## 8. Personal names and surnames

| Name                           | Pattern                  | Forms                                            |
| ------------------------------ | ------------------------ | ------------------------------------------------ |
| `Peter`, `Pavol`, `Karol`      | `chlap`, mobile vowel    | `Petra, Petrovi, s Petrom`; `Pavla`; `Karla`     |
| `Ján`, `Martin`, `Tomáš`       | `chlap`                  | `Jána, Jánovi`; `Martina`; `Tomáša`              |
| `Juraj`, `Ondrej`              | `chlap`, soft stem       | `Juraja, Jurajovi, s Jurajom`                    |
| `Janko`, `dedo`, `strýko`      | `chlap` sg., `-ovia` pl. | `Janka, Jankovi`; `deda, dedovi`; pl. `dedovia`  |
| male surname in `-a`           | `hrdina`                 | `Hlinka → Hlinku, Hlinkovi, s Hlinkom`           |
| male surname in `-ský/-ný/-ý`  | adjective `pekný`        | `Jesenský → Jesenského, Jesenskému, s Jesenským` |
| `Jana`, `Eva`, `Zuzana`        | `žena`                   | `Jany, Jane, s Janou`                            |
| `Mária`, `Lucia`, `Natália`    | `ulica` with `-ia`       | `Márie, Márii, s Máriou`                         |
| female surname in `-ová`       | adjective `pekná`        | `Nováková → Novákovej, s Novákovou`              |
| female surname in `-ská`, `-á` | adjective                | `Jesenská → Jesenskej, s Jesenskou`              |

`pani` (Mrs/Ms) does not decline: `s pani Novákovou`, `pani Novákovej`. `pán` declines: `s pánom Novákom`, `pánovi Novákovi`. In direct address both stay nominative: `Pán Novák, ...` (`pane` belongs to service language).

Foreign names decline when they end in a consonant or `-a`: `Smith → Smitha`, `Obama → Obamu`. For foreign women's surnames, follow the Slovak source you are working from: traditional Slovak usage adds `-ová` (`Merkelová`), but do not add or strip it on your own initiative.

## 9. Checklist for any noun form you generate

1. Gender from the dictionary, not from the last letter alone.
2. Masculine: animate or inanimate? The accusative and the plural depend on it.
3. Masculine inanimate: genitive `-a`/`-u` and locative `-e`/`-u`/`-i` known or verified?
4. Genitive plural: lengthening or inserted vowel correct; rhythmic law respected?
5. Plural-only noun or plural place name? Plural agreement.
6. Agreement words (adjective, pronoun, past tense) match the noun's gender and animacy.
