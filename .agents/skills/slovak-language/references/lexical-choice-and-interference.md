# Lexical Choice and Interference

Use this when translating from English, reviewing generated or learner Slovak, or vetting example sentences. Most "grammatical but wrong" Slovak comes from one English word mapped to one Slovak word, from false friends, or from Czech leaking in.

## 1. One English word, several Slovak verbs

| English                       | Slovak                                                                                                                                                                                                                                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **get**                       | receive `dostať` (`Dostal som list.`); obtain `získať`; reach a place `dostať sa do/na` (`Ako sa dostanem na stanicu?`); get up `vstať`; get on/off `nastúpiť do` / `vystúpiť z`; get used to `zvyknúť si na + acc.`; get + state usually a perfective verb: `unaviť sa`, `nahnevať sa`, `stratiť sa`, `zlepšiť sa` |
| **get married**               | man `oženiť sa`, woman `vydať sa`, couple `zobrať sa`                                                                                                                                                                                                                                                               |
| **make**                      | `urobiť/robiť` (do, make generally); food `uvariť`, `pripraviť`, `upiecť`; manufacture `vyrobiť`; make someone do `prinútiť niekoho + inf.`; make a mistake `urobiť chybu`, `pomýliť sa`; make a decision `rozhodnúť sa`                                                                                            |
| **make sense**                | `Má to zmysel.` or `Dáva to zmysel.` (both accepted); not `*Robí to zmysel.`                                                                                                                                                                                                                                        |
| **take**                      | take hold of `vziať, zobrať`; take time `trvať` (`Trvá to hodinu.`); take a bus `ísť autobusom`; take medicine `užiť liek`, regularly `brať lieky`; take a photo `odfotiť`, `urobiť fotku`; take part `zúčastniť sa na + loc.` (safest; `+ gen.` also occurs); take off clothes `vyzliecť si`                       |
| **ask**                       | a question `opýtať sa / pýtať sa niekoho (na niečo)`; for a favour `poprosiť / prosiť niekoho o niečo`; request formally `požiadať o`; invite `pozvať`                                                                                                                                                              |
| **know**                      | a fact, how to `vedieť` (`Viem, kde býva.` `Viem plávať.`); a person or place `poznať`; master a language or skill `ovládať`                                                                                                                                                                                        |
| **learn / study / teach**     | learn `učiť sa`, `naučiť sa` (succeed in learning); study at university or in depth `študovať`; teach `učiť`; find out `dozvedieť sa`                                                                                                                                                                               |
| **meet**                      | meet up, run into `stretnúť (sa)`; get acquainted `zoznámiť sa`; get to know `spoznať`                                                                                                                                                                                                                              |
| **visit**                     | `navštíviť`; go see someone `ísť za niekým` (`Idem za babkou.`); sightsee `pozrieť si`                                                                                                                                                                                                                              |
| **like / love**               | like `mať rád/rada`; appeal `páčiť sa + dat.`; love (people, romantic or family) `ľúbiť`; love strongly, also things `milovať`; would like `chcel/a by som`, ordering `dal/a by som si`                                                                                                                             |
| **can / may**                 | possibility, permission `môcť`; know how `vedieť` (`Viem plávať.`); formal permission `smieť` (`Smiem ďalej?`); with perception verbs no modal: `Vidím ho.` `Počujem ťa.`                                                                                                                                           |
| **must / should**             | must `musieť`; don't have to `nemusieť`; must not `nesmieť`; should `mal/a by som`; be supposed to `mať` (`Mám prísť o piatej.`); need to `treba`, `potrebovať`                                                                                                                                                     |
| **let**                       | allow `nechať`, `dovoliť` (`Nechaj ma ísť.`); let's `poďme + inf.` or 1pl imperative (`Poďme jesť.` `Pozrime sa.`)                                                                                                                                                                                                  |
| **leave**                     | depart `odísť`; abandon `opustiť`; leave something behind `nechať` (`Nechal som kľúče doma.`)                                                                                                                                                                                                                       |
| **play**                      | children play `hrať sa`; a game or sport `hrať + acc.` (`hrať futbal`); an instrument `hrať na + loc.` (`hrať na klavíri`); a role `hrať`                                                                                                                                                                           |
| **try**                       | `skúsiť`; attempt (formal) `pokúsiť sa`; test, try out `vyskúšať`; taste `ochutnať`; try on `vyskúšať si`, `skúsiť si`                                                                                                                                                                                              |
| **think**                     | opinion `myslieť si, že…`; think of `myslieť na + acc.`; ponder `rozmýšľať / premýšľať o`; seem `zdať sa` (`Zdá sa mi, že…`)                                                                                                                                                                                        |
| **feel**                      | + state `cítiť sa` (`Cítim sa dobre.`); sense, smell `cítiť`; have a feeling `mať pocit, že…`; feel like `mať chuť na + acc.` / `+ inf.`                                                                                                                                                                            |
| **remember / remind**         | retain `pamätať si`; recall `spomenúť si na + acc.`; memorize `zapamätať si`; remind `pripomenúť`                                                                                                                                                                                                                   |
| **miss**                      | someone `chýbať + dat.` (`Chýbaš mi.` = I miss you); a bus `zmeškať`; a target `netrafiť`; skip `vynechať`                                                                                                                                                                                                          |
| **wait / expect / hope**      | `čakať na + acc.`; wait a moment `počkať`; expect `očakávať`; hope `dúfať`                                                                                                                                                                                                                                          |
| **live**                      | reside at an address `bývať` (`Bývam v Košiciach.`); live a life, exist `žiť` (`Žije v zahraničí.`)                                                                                                                                                                                                                 |
| **speak / say / tell / talk** | speak, talk `hovoriť`; say or tell once `povedať`; chat, narrate `rozprávať (sa)`                                                                                                                                                                                                                                   |
| **look / see / watch**        | look at `pozerať sa / pozrieť sa na + acc.`; see `vidieť`; watch TV or a film `pozerať`; follow closely `sledovať`; look for `hľadať`; look like `vyzerať ako`; look forward to `tešiť sa na`                                                                                                                       |
| **listen / hear**             | `počúvať` / `počuť`                                                                                                                                                                                                                                                                                                 |
| **put**                       | generic `dať`; lay `položiť`; stand upright `postaviť`; insert `vložiť`; hang `zavesiť`; put on clothes `obliecť si`, shoes `obuť si`, hat/glasses `dať si, nasadiť si`                                                                                                                                             |
| **wear**                      | habitually `nosiť`; have on now `mať na sebe`                                                                                                                                                                                                                                                                       |
| **borrow / lend**             | borrow `požičať si (od niekoho)`; lend `požičať (niekomu)`                                                                                                                                                                                                                                                          |
| **bring / take someone**      | carrying `priniesť`; leading `priviesť`; by car `priviezť`; drive someone `odviezť`; take along `vziať so sebou`                                                                                                                                                                                                    |
| **spend**                     | money `minúť`; time `stráviť`                                                                                                                                                                                                                                                                                       |
| **save**                      | money, time `ušetriť`; rescue `zachrániť`; a file `uložiť`                                                                                                                                                                                                                                                          |
| **happen**                    | `stať sa` (`Čo sa stalo?`); be going on `diať sa` (`Čo sa deje?`)                                                                                                                                                                                                                                                   |
| **become**                    | `stať sa + instr.` (`Stal sa lekárom.`)                                                                                                                                                                                                                                                                             |
| **understand**                | `rozumieť + dat.` (`Rozumiem ti.` `Rozumiem po slovensky.`); grasp `pochopiť / chápať`                                                                                                                                                                                                                              |

## 2. English "to be" sentences that Slovak builds differently

| English              | Slovak                                                        |
| -------------------- | ------------------------------------------------------------- |
| I'm cold / hot       | `Je mi zima / teplo.` (weather: `Je zima.`)                   |
| I'm hungry / thirsty | `Som hladný/á.` `Mám hlad.` / `Som smädný/á.` `Mám smäd.`     |
| I'm 25               | `Mám 25 rokov.`                                               |
| I'm right            | `Mám pravdu.`                                                 |
| I'm sorry            | apology `Prepáč(te).`; regret `Je mi to ľúto.` `Mrzí ma to.`  |
| I'm afraid (that)    | `Bojím sa.`; polite `Obávam sa, že…`                          |
| I'm interested in    | `Zaujímam sa o + acc.`                                        |
| I'm late             | `Meškám.`                                                     |
| I'm in a hurry       | `Ponáhľam sa.`                                                |
| I'm bored            | `Nudím sa.`                                                   |
| I'm fine             | `Mám sa dobre.` `Som v poriadku.`                             |
| It's my turn         | `Som na rade.`                                                |
| There is / are       | `Je / sú…`, `Nachádza sa…` (formal); none: `Nie je…`, `Niet…` |

## 3. Small words with many jobs

| Slovak         | Uses                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| `prosím`       | please; here you are; you're welcome; pardon? (`Prosím?`); hello on the phone |
| `nech sa páči` | here you are; please go ahead; help yourself                                  |
| `prepáčte`     | sorry; excuse me (getting attention)                                          |
| `s dovolením`  | excuse me (passing through)                                                   |
| `niet za čo`   | you're welcome (also `Nemáš/nemáte za čo.`, `Rado sa stalo.`)                 |
| `na zdravie`   | cheers; bless you (after a sneeze)                                            |
| `dobrú chuť`   | enjoy your meal                                                               |
| `ešte`         | still; yet (with negation: `ešte nie`); more (`ešte kávu?`)                   |
| `už`           | already; any more (with negation: `už nie`)                                   |

## 4. English–Slovak false friends

| Slovak        | Means                                            | Not                                  |
| ------------- | ------------------------------------------------ | ------------------------------------ |
| `aktuálny`    | current, topical                                 | actual (= `skutočný`)                |
| `eventuálne`  | possibly, alternatively                          | eventually (= `nakoniec`)            |
| `sympatický`  | likeable, nice                                   | sympathetic (= `chápavý`)            |
| `kontrolovať` | check, inspect                                   | control (= `ovládať, riadiť`)        |
| `reklama`     | advertisement                                    | reclamation                          |
| `reklamácia`  | complaint about a product                        |                                      |
| `prospekt`    | brochure, leaflet                                | prospect                             |
| `konkurz`     | selection round, audition; also bankruptcy       | concourse                            |
| `gymnázium`   | academic secondary school                        | gym (= `telocvičňa`, `posilňovňa`)   |
| `trafika`     | newsagent's kiosk                                | traffic (= `doprava`)                |
| `prezervatív` | condom                                           | preservative (= `konzervačná látka`) |
| `evidencia`   | records, register                                | evidence (= `dôkaz`)                 |
| `dres`        | sports jersey                                    | dress (= `šaty`)                     |
| `recept`      | recipe; prescription                             | receipt (= `bloček`, `doklad`)       |
| `benzín`      | petrol, gasoline                                 | benzene                              |
| `citlivý`     | sensitive                                        | sensible (= `rozumný`)               |
| `šéf`         | boss                                             | chef (= `šéfkuchár`)                 |
| `kabinet`     | subject room (school, `kabinet fyziky`); cabinet |                                      |
| `smoking`     | tuxedo                                           | smoking (= `fajčenie`)               |
| `ordinácia`   | doctor's surgery/office                          | ordination                           |

## 5. Calques from English to remove

| Calque                                       | Natural Slovak                      |
| -------------------------------------------- | ----------------------------------- |
| `Umyl som si moje ruky.`                     | `Umyl som si ruky.`                 |
| `On je môj brat. Ja mám auto.` (no contrast) | `Je to môj brat. Mám auto.`         |
| `Mám jedno auto.` (article sense)            | `Mám auto.`                         |
| `Bolo mi povedané, že…`                      | `Povedali mi, že…`                  |
| `Ďakujem pre pomoc.`                         | `Ďakujem za pomoc.`                 |
| `Čakám pre autobus.`                         | `Čakám na autobus.`                 |
| `Idem tam pre dva týždne.`                   | `Idem tam na dva týždne.`           |
| `Som 25 rokov starý.`                        | `Mám 25 rokov.`                     |
| `Nie som schopný prísť.` (meaning can't)     | `Nemôžem prísť.`                    |
| `Maj dobrý deň!`                             | `Pekný deň!` `Prajem pekný deň.`    |
| `Na konci dňa…` (at the end of the day)      | `Nakoniec…`, `V konečnom dôsledku…` |
| `Robí to zmysel.`                            | `Má to zmysel.` / `Dáva to zmysel.` |

Location prepositions that do not match English: `na univerzite`, `na pošte`, `na stanici`, `na úrade`, `na koncerte`, `na dovolenke`, `na Slovensku`, `na Ukrajine` vs. `v škole`, `v práci`, `v obchode`, `v kine`, `v Bratislave`, `v Česku`. Learn them as pairs: [valency-and-prepositions.md](valency-and-prepositions.md) §4.

## 6. Czech interference (bohemisms)

Slovak and Czech are close enough that Czech forms slip into Slovak text, including model-generated text. Normative Slovak replaces them:

| Avoid                      | Use                                                  |
| -------------------------- | ---------------------------------------------------- |
| `jedná sa o`               | `ide o`                                              |
| `ohľadne + gen.`           | `pokiaľ ide o`, `vzhľadom na`, `o`, `v súvislosti s` |
| `doporučiť`                | `odporučiť`                                          |
| `behom`                    | `počas`, `za` (`za hodinu`)                          |
| `obdržať`, `obdŕžať`       | `dostať`, `prijať`                                   |
| `kľud`, `kľudný`, `kľudne` | `pokoj`, `pokojný`, `pokojne`                        |
| `tlačítko`                 | `tlačidlo`                                           |
| `za účelom`                | `na`, `s cieľom`, `aby`                              |
| `prevádzať opravy`         | `robiť / vykonávať opravy`                           |
| `jak`                      | `ako`                                                |
| causal `kvôli`             | `pre`, `z dôvodu`, `v dôsledku` (see valency §5)     |

Also avoid causal `nakoľko` (`Nakoľko prší…` → `Keďže prší…`).

Forms that are simply Czech: `jsem/byl jsem` (Slovak `som/bol som`), `byly` (`boli`), `ř`, `ě`, `ů`, infinitive `-t` (`-ť`), `já` (`ja`), `děkuji` (`ďakujem`), `na shledanou` (`dovidenia`).

Czech–Slovak false friends: Slovak `horký` = bitter (Czech `horký` = hot; Slovak hot = `horúci`); Slovak `stávka` = bet (strike = `štrajk`); Slovak `pivnica` = cellar (not a pub).

## 7. Loanword spelling

Use the adapted Slovak spelling where the dictionary has one: `tím` (team), `víkend`, `džús`, `manažér`, `líder`, `softvér`, `hardvér`, `šou`, `džínsy`, `e-mail`, `mobil`, `počítač`. Do not reintroduce English spellings in Slovak sentences (`*team`, `*weekend`) unless quoting a brand or title.
